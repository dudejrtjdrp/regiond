# 갈래말래 (가제)

**엔드리스 정착지 성장 · 타워디펜스 웹게임.** 스타듀밸리의 손맛 + 역할군 국가경영.
마차가 멈춘 자리에 모닥불 하나. 주민은 0명이다. 도끼질로 시작해 정착지를 키우고,
사람이 하나둘 걸어 들어오고, 티어가 오를 때마다 땅이 넓어지고 새 건물이 열린다. **끝은 없다.**

## v3.1 — 진행 감독 (`docs/GDD3.md` §11 · 서버·클라 구현 완료)

**대원칙: 시간은 아무것도 열지 않는다.** 감정의 날·어전 회의·조언·무역 오퍼·유물·웨이브 예고 —
저절로 뜨는 것은 하나도 없다. 게임의 모든 문은 **콘텐츠 사슬 10장**(`data/chapters.json`)이 열고,
그 사슬은 `server/engine/progression.js`(진행 감독) 하나가 관장한다.

| 장 | 이름 | 여는 조건(전부 행동) | 새 동사 | 보상 |
|---|---|---|---|---|
| 1 | 불씨 | 시작 | 이동 · 나무 베기(E) | 모닥불 · **배치대 열림** |
| 2 | 첫 지붕 | 목재 10 | 배치(천막만) | 천막 · 저장 궤짝 |
| 3 | 허기 | 천막 완공 | 어로 · 개간 | 식량 20 → 오두막 열림 |
| 4 | 첫 이웃 | 오두막 완공 | **주민 유입** · 지시(우클릭) | 첫 주민 · 곡창 |
| 5 | 마을의 꼴 | 주민 3 + 곡창 | 주민 노동 · 저장 | **촌락 승격(티어 연출)** |
| 6 | 땅의 비밀 | 주민 5 | **채석 · 감정** | **감정의 날 컷신 + 태그 + 역할** |
| 7 | 낯선 발자국 | 감정 완료 | 정찰 · 울타리 · 화살탑 | **첫 웨이브** |
| 8 | 장사꾼의 길 | 첫 웨이브 격퇴 | 무역 | 첫 상단 |
| 9 | 나라의 격 | 교역소 | 어전 회의 · 유물 | 첫 회의 |
| 10+ | 끝이 없는 길 | 사당(성지) | — | 티어 승격이 장을 대신한다 |

- **감정의 날**은 3일차 자동 발동이 아니라 **감정소(측량소, 목재 60·석재 30)를 세우고 눌러야** 열린다
- **안내 시스템**: 대상 위 상호작용 라벨(「E — 나무 베기」) · 퀘스트 마커(월드 화살표 + 화면 밖 가장자리 화살표) ·
  목표 카드 클릭 = 카메라 점프 · 자원 팝의 목표 잔여(「목재 +4 (천막까지 6)」) · **같은 오류 두 번이면 해결 말풍선 + 마커**
- **잠긴 것은 화면에 없다**: 지을 게 없으면 [세우기] 단추 자체가 없고, 웨이브·시장·각료는 뷰에서 필드째 빠진다
- **모달 자동 팝 전면 금지**: 어전 회의·조언·오퍼·유적은 오른쪽 알림에만 쌓인다 (여는 건 언제나 플레이어)
- **월드 256×256** · 영토 경계는 **말뚝 + 밧줄** 픽셀 연출(미니맵은 굵은 경계)

## v3 — 엔드리스 정착지 성장 (`docs/GDD3.md` §1~§10)

| 축 | 무엇이 바뀌었나 |
|---|---|
| **성장 아크** | 정착지 티어 0~6+(야영지→개척촌→촌락→마을→읍→도시→왕도…). 조건이 차면 **본부의 [승격] 단추**로 영토 반경을 넓힌다(6→9→12→16→20→25→29). 건물·기능·UI 는 사슬(장)이 연다. 개척령(expand)은 폐기 |
| **인구 0 시작** | 주민은 **주거 수용력 + 식량 여유 + 매력도** 조건에서 한 명씩 걸어온다(천막1/오두막2/가옥4/저택6). 이름·외형이 랜덤으로 붙고, 60명까지는 1유닛 = 1명 |
| **개인 스킬·스윙** | 농사·벌목·채광·건설·전투 5종(Lv1~20). 액션은 **스윙 단위** — 서버가 쿨타임(1.2초, 레벨당 −3%, 하한 0.5초)·사거리·노드별 스윙 카운트를 판정한다. 도구는 레벨로 열린다(돌→철→강철) |
| **시간 감속** | **1게임일 = 실시간 10분**. 일 틱(경제 정산)과 실시간(스윙·전투)·서브틱(전투 시뮬 0.25초)이 분리돼 있다 |
| **엔드리스 웨이브** | 시즌 종료·결산은 폐기(→**연대기**). **7장(낯선 발자국)에서 흔적을 살핀 뒤부터** 4~6일 간격으로 끝없이 온다. 늑대→도적→해적→바이킹→오우거→드래곤 로테이션, `파워 = 560 × 1.07ⁿ × 난이도 × 규모보정` |
| **실시뮬 전투** | 로지스틱 일괄 판정 폐기. 적 유닛이 걸어와 울타리를 두드리고, 터렛이 쏘고, 민병이 붙고, **플레이어가 검을 들고 참전**한다(죽음 없음 — 다운). 결정론 서브틱 + 리플레이 타임라인 |
| **건물 대확충** | 33종(주거4·생산12·군사7·발전6·장식4). **개별 건물 티어** — 건물을 클릭해 그 한 채만 올린다. 수리도 건물 단위 |
| **울타리 조각** | 자동 성곽 링 폐지. **드래그로 선을 그으면** 타일 단위 조각으로 서고, 목책→석벽으로 올린다. 문 조각도 따로 |
| **경제 재보정** | 시즌 총량 기준 → **레이트 기준**. 콥더글러스·가격·무역 공식과 계수는 **한 줄도 안 바꿨다** — 부처·각료·역할은 티어 3부터 가동하고, 그 전엔 플레이어 스윙과 주민 개별 채집이 유일한 생산원 |

프로토콜 정본은 **`docs/PROTOCOL.md` v3.1** 이다. 클라이언트는 그 문서만 보고 만든다.

> 클라이언트도 v3 로 전면 재작성됐다 — 마차 도착 오프닝, 스윙 노동(누르고 있으면 연타),
> 점진 공개 HUD, 티어업 연출(영토 말뚝 + 건물 도감), 울타리 드래그, 실시간 웨이브 전투, 연대기.
> 서버가 실제로 받는 명령·보내는 이벤트의 정본은 언제나 `docs/PROTOCOL.md` 다.

- 서버: Node 22 ESM + express + socket.io (외부 빌드 스텝 없음)
- 클라: `public/` — 바닐라 JS 클래식 스크립트(`GM` 네임스페이스), CDN 없음.
  **화면의 주인공은 단일 월드 캔버스다** — **256×256** 공유 월드를 직접 굴린다.
  카메라(WASD·방향키·가장자리·미니맵·휠 줌 16/24/32), 아바타 걷기와 **스윙 노동**,
  주민 드래그 선택·우클릭 명령, 건물 고스트 배치·개간 드래그, **울타리 선 긋기**,
  실시간 웨이브 전투와 검 참여, 캐릭터 생성기·초대 코드·명부·한 줄 대화가 전부 여기 있다.
  이펙트 계층(`fx.js`)이 스윙 궤적·명중 정지·파편·자원 팝·화면 흔들림을 전담한다.
  UI 는 문명식 정보 구조 + 스타듀밸리 톤(양피지·목재 픽셀 프레임). 도트 스프라이트·아이콘·효과음까지 코드로 생성하고,
  외부 에셋은 동봉한 한글 도트 폰트 `public/assets/fonts/Galmuri11.woff2`(SIL OFL) 하나뿐이다.
- 모든 수치는 `data/*.json` 다이얼로 외부화되어 있다 (매직넘버 금지)

## 실행

```bash
npm install        # Node 22 이상. 외부 빌드 스텝 없음
npm start          # http://localhost:3000
```

`PORT` 환경변수로 포트를 바꿀 수 있다. 브라우저에서 열면 바로 **타이틀 화면**이다.

1. **[새 정착지]** → 이름 · 난이도 3택(이야기 / 왕국 / 시련) · **캐릭터 생성**(피부6 · 머리8 · 머리색10 · 의상6 · 의상색10)
   → **[마차에 오른다]**. **역할은 여기서 고르지 않는다** — 야영지에는 각료가 없다.
   6장에서 **감정소를 세우고 [땅을 감정한다]** 를 눌러야 태그가 드러나고 **관제 선포**로 자리가 갈린다.
2. **[초대 코드로 참여]** → 다른 사람이 연 정착지의 초대 코드(gameId)를 붙여 넣으면 **한 정착지를 1~5인이 함께** 굴린다.
   내 초대 코드는 게임 화면 좌상단에서 복사할 수 있다.
3. **[이어하기]** → `saves/` 의 스냅샷을 잇는다. (구버전 스냅샷은 폐기되고 새 정착지가 열린다)

서버 없이 화면만 둘러보려면 `http://localhost:3000/?mock=1` (구경 모드 — 가짜 월드로 UI 만 돈다).
같은 땅을 다시 받고 싶으면 `?seed=20260804` — 하니스·스모크가 쓰는 손잡이다(평소에는 서버가 새 씨앗을 고른다).

## 명령

| 명령 | 설명 |
|---|---|
| `npm start` | 서버 기동 (정적 파일 + socket.io + 디버그 REST) |
| `npm test` | 단위 테스트 + E2E **135개** (`test/progression.test.js` — **30게임일 방치 시 모달 0건 · 시작 주민 0 · 장 사슬 순차** 회귀 포함) |
| `npm run e2e` | E2E 만 (4편: 전체 루프 · 정보 비대칭 · **안개 즉시 공개** · 멀티 왕복+재접속) |
| `npm run harness` | UI 규칙 정적 검사 + jsdom 클라 하니스 **29항목**. ★ v3.1 재작성 — **목표 카드와 마커가 가리키는 것만 보고** 1장→6장(감정)까지 간다(각본 없음). 뒤이어 7장 이후(울타리·개축·웨이브·연대기)와 구경 모드 회귀 |
| `npm run smoke` | **실브라우저(헤드리스 크롬) 연기 검사 94항목** — 진짜 마우스로 타이틀→개척 시작→오프닝 건너뛰기→**상호작용 라벨(「E — 나무 베기」) 확인**→연타 스윙(파편·자원 팝)→배치대·고스트 배치→**마커 따라 6장(감정)까지**→안개 속 걷기(즉시 공개)→**주민 하역 수치("+N 목재")**→**밝기 하한(칠흑 금지·건설 모드 암전 없음)**→**256맵 프레임 측정**(한 프레임 그리기 <16ms). 크롬이 없으면 경고만 남기고 건너뛴다 (`CHROME_PATH=... npm run smoke`) |
| `npm run check:ui` | 장식 요소 `pointer-events:none` · `[hidden]` 안전장치 · 화면 금지어 19종 · **폐기된 프로토콜 명령 사용 금지** · 규약 판번호 일치 · 스크립트 목록 정적 검사 |
| `npm run simulate` | 무접속 시뮬레이션 20회 × 85게임일 → 밸런스 체크포인트 리포트 (seed 42 기준 **4/4**). 판을 코어에 나눠 돌린다(`--workers`, 결과 동일). 봇도 **장 사슬을 따라간다**(목표 카드의 조건을 읽고 그것만 한다) |

> 하니스와 스모크는 **씨앗을 고정**해 돌린다(`?seed=20260804`). 매번 다른 땅을 받으면
> 실패가 코드 탓인지 지도 탓인지 가려낼 수 없기 때문이다. 다른 땅으로 돌려 보려면 `SMOKE_SEED=… npm run smoke`.

> **잘 안 열릴 때** — 화면이 「땅을 살피는 중…」에서 멈추면 대개 **예전 서버가 아직 떠 있는 것**이다.
> 서버 창을 모두 닫고(`Get-Process node | Stop-Process`) 다시 `npm start`.
> 포트가 이미 잡혀 있으면 서버가 그 사실을 직접 알려 준다. 화면도 몇 초 안에 까닭을 적어 준다.

## 배포 (Render 무료)

`render.yaml` 블루프린트가 들어 있다. 저장소를 Render 에 연결하고 **Blueprint** 로 만들면 끝이다
(`npm install` → `npm start`, 헬스체크 `/api/health`, `NODE_ENV=production`).
**처음 하는 사람 기준 단계별 안내: [`docs/DEPLOY.md`](docs/DEPLOY.md).**

무료 플랜의 두 가지 성질만 알고 있으면 된다 — **15분 미접속 시 슬립**(첫 접속이 30초쯤 느리다),
**재시작하면 세이브 초기화**(디스크가 휘발성이다. 남기려면 유료 플랜 + 영구 디스크 + `SAVES_DIR`).

| 환경변수 | 기본 | 하는 일 |
|---|---|---|
| `PORT` / `HOST` | `3000` / `0.0.0.0` | 플랫폼이 준다. 컨테이너에서는 반드시 `0.0.0.0` 바인딩 |
| `NODE_ENV` | — | `production` 이면 **개발 뒷문(`/api/debug/*`)이 통째로 404** |
| `DEBUG_API` | — | `1` = 운영에서도 강제 개방(임시 점검용), `0` = 개발에서도 차단 |
| `SAVES_DIR` | `saves/` | 세이브 폴더. 영구 디스크의 마운트 경로를 준다 |
| `ANTHROPIC_API_KEY` | — | 있으면 사건 문장을 Claude 가 윤색한다(없어도 게임은 그대로 돈다) |

## 개발 패널

게임 화면에는 단추를 두지 않는다. **Ctrl + `** 로만 열린다 → 하루 길이 / 멈춤 / 하루 진행 / 씨앗 지정.
같은 기능의 REST: `POST /api/debug/{speed,pause,step,seed}`.

> ★ **운영 배포(`NODE_ENV=production`)에서는 이 문이 잠긴다** — `/api/debug/*` 는 전부 404 로 답하고,
> 개발 패널은 `/api/health` 의 `debugApi:false` 를 보고 **아무 말 없이 스스로 접힌다**(Ctrl+` 를 눌러도 열리지 않는다).
> 잠깐 열어야 하면 `DEBUG_API=1` 을 준다.

- **첫 30분** — 마차가 멈추고 자막 넉 줄이 흐른 뒤(언제든 건너뛸 수 있다) 야영지 HUD 는
  **자원 3칸 + 목표 카드**뿐이다. 목표는 *나무 세 번 → 목재 10 → 천막 → 식량 10 → 개간 → 오두막 → 첫 주민*
  순으로 이어지고, 새 기능이 열릴 때마다 **한 줄짜리 코치마크**가 그 자리를 짚어 준다.
- **맨손으로 내린다** — 마차에서 내릴 때 목재는 **0**이다(모닥불만 이미 피워져 있다).
  첫 천막(목재 10)은 반드시 제 손으로 나무를 베어야 선다 — **나무 한 그루 = 3스윙 = 목재 13**, 즉 한 그루가 천막 한 채다.
- **식량은 두 갈래** — 기름진 땅·밭은 **여물어야** 거두고(파종→새싹→자람→여묾), **물가는 언제든 건진다(어로)**.
  대신 물목의 물고기는 유한해서 훑으면 바닥나고 며칠에 걸쳐 다시 몰려온다.
- **점진 공개** — 화면은 `state.unlocked` 만 보고 켜진다. 안 열린 것은 **회색이 아니라 아예 없다**.
  개척촌에서 인구 칸과 주민 단추, 촌락에서 울타리·위협 배지, 마을에서 각료·솜씨·교역이 하나씩 늘어난다.
- **티어업** — 팡파레와 함께 **영토 말뚝이 새 반경으로 박히고**, 새로 열린 건물이 **도감 카드**로 펼쳐진다.
- **건물은 전부 손수 자리를 잡는다.** 개별 건물마다 티어가 따로다 — 건물을 눌러 그 한 채만 올린다.
  손수 고른 자리에만 **이웃한 자원 자리의 덕(인접 보너스)** 이 붙는다(건축가 재임 시).
- **웨이브** — 경보 → 적이 걸어와 울타리를 두드리고 → 터렛이 쏘고 민병이 붙는다.
  **직접 검을 들고 붙어도 된다**(적 곁에서 누르고 있기). 쓰러져도 죽지 않는다 — 모닥불에서 다시 일어난다.
- **멀티**: 초대 코드를 나눠 주면 함께 개척한다. 남의 도끼질도 화면에 보인다. 역할은 마을(티어 3)부터.

## 화면 규칙 (지키지 않으면 `npm run check:ui` 가 막는다)

1. **장식 요소는 반드시 `class="decor"`** — `.decor{pointer-events:none}` 이 걸려 있다.
   배경 캔버스가 폼 위를 덮어 클릭을 먹는 사고를 원천 차단한다.
2. **`[hidden]{display:none !important}` 전역 규칙을 지운다면 반드시 대안을 둔다.**
   저자 stylesheet 의 `display` 선언은 브라우저 기본 `[hidden]{display:none}` 을 이긴다 —
   `.shell{display:flex}` + `<div hidden>` 조합이 화면 전체를 덮어 로비 입력을 막았던 적이 있다.
3. **화면 문구는 세계관 언어만** — 개발자 용어(하루를 세는 단위·자료구조 이름 등)는 검사에서 걸린다.
