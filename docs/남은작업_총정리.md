## 1. ✅ 이동 중 주기적 렉 — 원인 규명·수정 완료 (2026-08-08)

**범인은 안개가 아니라 지형 청크 굽기였다.** `chunkCanvas` 가 16×16칸 한 장을 한 프레임에 통째로 구웠고,
처음 밟는 땅에서는 `terrainBlob` 조각 256개가 전부 캐시 밖이라 조각마다 캔버스를 새로 잡고
베지에 여덟 획 + clip 으로 경계를 오려 붙인다. 실측 **조각 하나 0.347ms(cold) / 0.0007ms(warm)** →
**청크 한 장 70~140ms**. 걸어서 청크 경계를 넘으면 두세 장이 한 프레임에 몰렸다 — 주기 = 16칸 걷는 시간.

고친 것(그림은 한 픽셀도 안 바뀐다):
- 굽기를 **줄 단위**로 쪼개 프레임당 4ms(급하면 9ms)만 쓴다
- 다 굽기 전에는 그 자리에 **지형 바탕색**을 깐다(축소지도와 같은 색)
- **화면 밖 한 겹을 미리 굽는다** — 걸음이 닿기 전에 끝나므로 밋밋한 한때가 눈에 안 띈다
- 청크 캐시 교체를 구운 순서 → **최근 쓴 순서(LRU)** 로
- `minimap.js` — Sprint 3 의 `lastDraw`/`minimapHz()`/`buildStatics` 가 **선언만 되고 안 쓰이고 있었다**. 배선

측정(구경 모드 900프레임 뱀걸음, 3회 A/B): 최악 **124~154ms → 28~40ms**, 100ms 초과 **3~4회 → 0회**.
스크린샷 픽셀 차 338/838,400(0.04%, 전부 움직이는 것들).

> ⚠ **남은 확인 하나**: 클라우드에서는 `smoke_browser` 가 에셋 없음 때문에 9/12 에서 멎는다(고치기 전 코드도
> 똑같이 멎는다). 클라 렌더 변경의 진짜 게이트는 **유저 PC 에서 `npm run smoke`** — 배포 전에 한 번 돌릴 것.

## 8. ★ 병행 트랙 규칙 (실사고 4회 — 반드시)

- 반영 **직전에** `git log --oneline -1` 로 HEAD 재확인. 검증 9분 도는 사이에도 커밋이 얹힌다
- 겹치면 `git diff --name-only <기준선>..HEAD` → `git merge-file` 3-way
- 되돌리기는 `git show HEAD:<path> > <path>` — 마운트에선 `git checkout --` 이 실패한다(unlink 불가)
- 검증은 **HEAD 통짜 아카이브 + 내 파일 덮기** 병합 트리에서 전량 다시. pristine 복제본도 같이 두면
  「내가 깬 건가」를 그 자리에서 가린다
