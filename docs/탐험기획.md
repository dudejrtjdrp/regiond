# 탐험 기획 정본 v1 (§18) — 「저기엔 뭐가 있을까」

> 2026-08-06 작성. 잼 이후 확장의 설계 정본. 잼 범위(D·D-2·E)와의 경계는 §18-7에 명시.
> 대원칙 유지: 수치는 전부 `data/*.json` · 서버 권위 · 월드 결정론(보상 굴림은 `statRng`) · 퀘스트 마커 금지.

## §18-0. 설계 원칙

1. **이야기는 탐험이 시작한다.** NPC가 퀘스트를 주지 않는다. 플레이어가 흔적을 보고, 따라가고, 그 끝에서 이야기를 만난다.
2. **발견 리듬 30~60초.** 탐험 중인 플레이어는 60초 안에 반드시 하나를 만난다: 흔적·자원·비밀·수수께끼·전투·선택·이야기·강화 중 하나.
3. **MMO 퀘스트 금지.** 「N마리 잡기」「N개 모으기」류 금지. 모든 목표는 세계 안의 물리적 실체(연기, 발자국, 무너진 다리)로 존재한다.
4. **양이 아니라 조합.** 발견물 목록 250개는 필러가 된다. 대신 **사슬 템플릿 × 지역 변형 × 결말 분기**의 조합기(RimWorld 방식)로 수백 개의 창발 이야기를 만든다. 판마다 시드가 다르니 리플레이는 공짜다.
5. **밀당 리듬.** 낮 = 탐험 창(당김), 웨이브 = 귀환(밀침). Dave the Diver의 낮잠수/밤식당 구조. 「제때 돌아올 수 있는가」 자체가 긴장이다.

## §18-1. 발견 리듬의 수학 — 링 구조

맵 384², 본영 중앙(protectRadius 60). 발견물 밀도는 `data/trails.json density`로 구동(매직넘버 금지).

| 링 | 반경 | 정체성 | 발견물 간격(이동 타일) | 위험 |
|---|---|---|---|---|
| 링0 | 0~12 | 첫 사흘의 앞마당 (D-2) | 8~12 | 없음 |
| 링1 | 12~60 | 온대 확장·사람의 길 | 15~25 | 낮음 (야생동물) |
| 링2 | 60~140 | 바이옴 진입·3국 국경 | 25~35 | 중간 (조우·환경) |
| 링3 | 140+ | 전인미답 — 전설과 위험 | 35~50 | 높음 (귀환 자체가 도박) |

- 간격이 바깥으로 갈수록 **넓어지는** 이유: 먼 곳의 발견은 크고 드물어야 「멀리 간 보람」이 된다. 가까운 곳은 잘고 촘촘해야 첫 사흘이 안 빈다.
- 60초 규칙은 링0~1에서 엄격 적용, 링3에서는 「발견 없음」 자체가 긴장(빈 설원의 공포)이므로 의도적으로 느슨하게.

## §18-2. 방위별 정체성 (지도 사실 기반)

지도가 이미 정한 것: 북쪽 끝 고지 = 설산, 남쪽 끝 습지 = 밀림, 세 모서리 = AI 3국 도읍, 물·바위는 바이옴 불침범.

### 북 — 설산 「얼어붙은 과거」
- **왜 가나**: 철·석탄이 가장 풍부한데 **건설 불가** → 전진기지를 못 짓는 원정 구조. 갔다 오는 것 자체가 놀이.
- **고유 리스크**: 냉기 — 설산 체류 중 서서히 체력 잠식(모닥불 손일·귀환으로 회복). 리스크가 곧 타이머라 「조금만 더」의 유혹을 만든다.
- **기억에 남는 것**: 눈 속에 얼어붙은 옛 원정대 — 시체·짐·일지가 사슬로 이어진다. 설산의 이야기는 전부 「과거형」: 끝난 것들을 발굴한다.
- **연결**: 철·강재 경제(제련소 §17-9), 유물 시스템, 겨울 웨이브 적과 시각 통일.

### 남 — 밀림 「삼키는 생명」
- **왜 가나**: 숲·딸기 무성 = 식량·목재의 보고. 대신 시야가 짙게 제한된다(안개보다 어두운 수관).
- **고유 리스크**: 시야 — 조우가 코앞에서 일어난다. 독충·희귀 짐승. 밀림의 공포는 「안 보임」이다.
- **기억에 남는 것**: 덩굴이 삼킨 사원, 발광 버섯 골짜기, 밀림 심장의 거목. 밀림의 이야기는 전부 「현재진행형」: 살아 있는 것들이 자란다.
- **연결**: 식량 경제, 감정의 날 태그(fertile 계열), 동료 조우.

### 동·서 — 온대 「사람의 길」
- **왜 가나**: 3국 도읍(§17-16 방문)으로 가는 길목. 문명의 흔적이 이어진다 — 길, 마차 바퀴 자국, 국경 표석, 무너진 다리.
- **고유 리스크**: 사람 — 산적, 밀수꾼, 국경 분쟁. 자연이 아니라 인간이 위험.
- **기억에 남는 것**: 외교·무역과 얽힌 발견. 여기서 주운 것이 3국 관계를 움직인다(밀수품을 신고할까, 팔까).
- **연결**: 외교(§17-10)·무역·visitNation·깃발 점령(§17-14) — 새 영토 후보지가 이 방향에 많다.

### 중앙 링0 — 「앞마당」 (D-2의 답)
- 1~2일차용 짧은 사슬 1개 + 미시 발견 4~6개 **보장 생성**(시드 결정론, 본영 12타일 안).
- 예: 이상한 돌무더기(치우면 씨앗), 새 둥지(알 하나 — 가져갈까 둘까), 옛 우물(두레박 손일), 첫 발자국 사슬(→ 딸기 군락 or 다친 개).

## §18-3. 단서 사슬 시스템 (trails) — 핵심 신규 시스템

기존 재활용: cache 생성기(§17-17) + statRng + fog + 연대기 + E키 상호작용(§17-16).

### 데이터 스펙 — `data/trails.json`
```
chains: [{
  id, ring, biome?,            // 생성 조건 (링·바이옴 필터)
  steps: [{                    // 3~5개
    clue,                      // 흔적 종류: smoke|tracks|blood|cart|campfire|carving|...
    revealRadius,              // 조사 시 다음 흔적 주변 fog 공개 반경
    text                       // 연대기·대화창 한 줄 (한국어)
  }],
  endings: [{ weight, kind, ... }]  // cache|ruin|survivor|taggedLand|ambush|merchant
}]
density: { ring0: {...}, ... } // §18-1 간격 수치
```

### 규칙
- 생성: 월드 생성 시 시드로 사슬 배치(결정론). 시작 흔적만 지도에 존재, 나머지 단계는 **조사 순간 생성·공개**.
- 조사: 흔적에 E키 → 대화창(§18-6)으로 한 줄 이야기 + 다음 흔적 방향의 fog 원형 공개. **마커·화살표 금지** — 공개된 fog 안에서 눈으로 찾는다.
- 결말 분기: `endings` 가중치 굴림(statRng). 같은 시작이 판마다 다른 끝 — 마차 사슬이 이번 판엔 생존자, 다음 판엔 매복.
- 결말 `survivor`: 동료 후보 or 주민 +1(집들이 §17-6 경로 재활용). `taggedLand`: 태그 붙은 명당 발견 → 깃발 점령(§17-14)의 목적지 제공. `ambush`: 전투 — 리스크 없는 사슬은 복권일 뿐이다.

### 왜 재밌나
호기심에 **방향**이 생긴다(막연한 방랑 → 추적). 마커가 없어서 발견의 저작권이 플레이어에게 있다. 결말 분기 덕에 「마차를 보면 무슨 일이 생길지 모른다」는 기대가 유지된다.

## §18-4. 창발 이야기 템플릿 (사슬 원형 16종)

조합기: **원형 × 방위 변형 × 결말 분기** = 16 × 4 × 3~4 ≈ 200+ 이야기. 각 행: 시작 흔적 → 전개 → 결말 후보 (위험 / 재방문 가치).

| # | 원형 | 전개 | 결말 후보 |
|---|---|---|---|
| 1 | 부서진 마차 | 바퀴 자국 → 짐승 발자국 → 습격 현장 | 생존자 상인(영구 할인)·짐 궤·늑대 굴(전투) |
| 2 | 피어오르는 연기 | 폐야영지 → 꺼진 모닥불 → 발자국 | 부상 여행자(동료)·산적 매복·버려진 보급 |
| 3 | 핏자국 | 다친 짐승 추적 | 희귀 짐승(가죽)·포식자와 조우·새끼(길들이기 후보) |
| 4 | 낡은 이정표 | 지워진 글자 → 옛길 복원 | 폐촌(유물)·무너진 다리(bridgeworks 목적지)·함정 |
| 5 | 새겨진 바위 | 같은 문양 바위 3개 연결 | 고대 유적 개방·태그 명당·아무것도(허풍꾼의 낙서) |
| 6 | 반쯤 묻힌 지도 조각 | 조각 2~3개 수집(각기 다른 사슬 끝) | 대형 궤·설산 유적 좌표 — Terraria식 보물지도, 마커 없이 지형 묘사문으로 |
| 7 | 빈 배 (물가) | 표류 화물 → 상류 추적 | 침몰선(다리·매립 §17-13 활용처)·밀수꾼 은신처 |
| 8 | 얼어붙은 원정대 (북) | 일지 조각 → 대원 시신 순서대로 | 원정대장의 유물·그들이 찾던 광맥·냉기 속 최후 기록 |
| 9 | 덩굴 삼킨 사원 (남) | 입구 수수께끼(빛·물 퍼즐) | 사원 내부 유적 카드·수호 짐승·발광 버섯 재배지 |
| 10 | 국경 표석 (동서) | 위조 흔적 발견 | 밀수로(반복 무역 이득)·3국 분쟁 사건·신고(관계+) |
| 11 | 버려진 깃발 | 실패한 개척지 잔해 | 점령 후보지 정보·잔존 정착민(주민+)·저주받은 땅(악태그) |
| 12 | 낯선 발자국 (동물 아님) | 주기적으로 갱신되는 흔적 | 은둔 상인(희귀 재고, 위치 유동)·도망자·수집가 NPC |
| 13 | 부서진 기계 (유막 근처) | 부품 3종 회수 | 수리 → 영구 편의(자동 채집기 등)·폭발(리스크)·설계도 |
| 14 | 별똥별 낙하 (야간 사건) | 낙하 지점 fog 힌트 | 크레이터 광물 노드(영구)·이상한 알·불탄 숲(지형 변화) |
| 15 | 굶주린 무리 이동 (사건) | 이동 경로 예고 흔적 | 길목 회피·요격(가죽 대량)·본영 통과(방어전) |
| 16 | 노래하는 나무 (희귀) | 계절·날씨 조건에서만 반응 | 사기 버프·씨앗(본영에 심기 — Animal Crossing식 애착)·수액 자원 |

- **영구 흔적 원칙**: 14·15 같은 사건은 지도에 자국을 남긴다(크레이터, 불탄 숲). 세계가 판마다 다르게 상처 입는다 — 리플레이의 얼굴.
- **재방문 설계**: 12(은둔 상인)·16(노래하는 나무)·9(버섯 재배지)는 소진되지 않고 조건부 재활성 — 「다시 가볼 이유」 담당.

## §18-5. 미시 발견물 카탈로그 (사슬 사이를 채우는 것들)

사슬(굵은 실) 사이의 30~60초를 채우는 낱개 발견물(가는 실). 전부 E키 한 번 + 대화창 한 줄. `data/trails.json micro`로 링·바이옴별 배치.

| 종류 | 예 | 보상 |
|---|---|---|
| 채집 희귀변형 | 은빛 딸기·옹이 진 거목·수정 박힌 바위 | 자원 1.5~2배 + 연대기 |
| 한입 이야기 | 이끼 낀 석상·부러진 검·아이 신발 한 짝 | 세계관 파편(수집첩 등재) |
| 미니 선택 | 새 둥지의 알·덫에 걸린 여우·길가의 제단 | 자원 vs 사기 vs 후일 복선(여우가 나중에 은혜 갚기) |
| 소전투 | 벌집(연기 필요)·굴 속 오소리 | 식량·가죽, 준비 없으면 부상 |
| 무드 | 전망 바위(카메라 연출)·온천(체력 회복)·반딧불 골짜기 | 회복·사기 — 보상 없는 아름다움도 하나쯤 |

수집첩(잼후): 한입 이야기·희귀변형을 모으는 도감. Core Keeper식 — 채우는 것 자체가 장기 목표. 완성 보상은 능력치가 아니라 **지식**(전 지도 흔적 감지 반경 +1 등 탐험 강화로 순환).

## §18-6. 대화창 UI 스펙 (배치 D-5 — 잼 범위)

참고 이미지(포켓몬식 하단 대화창)를 Regiond의 종이·나무 시각 언어로 번역한다. 기존 토큰만 사용: `--paper/--wood/--ink/--gold`, Galmuri11.

### 구조
```
┌─[이름표]────────────────────────┐
│ ┌────┐                          │
│ │초상│  본문 텍스트 (타자기)      ▼ │
│ └────┘                          │
│         [선택지1] [선택지2]       │
└─────────────────────────────────┘
```
- **위치**: 화면 하단 중앙, `min(720px, 92vw)`, 하단 여백 12px. 대화 중 하단 HUD(건설 패널 포함)는 잠깐 숨김(fade) — D-1 하단 건설 UI와 자리 충돌 방지.
- **판**: `--paper` 배경, `--wood-dark` 3px 테두리 + `--wood-deep` 그림자 2px, 모서리 6px. 기존 모달·말풍선과 같은 계열이라 이질감 없음.
- **이름표**: 판 좌상단에 겹치는 작은 판(`--wood` 배경, `--paper-lit` 글자, 좌측 꼬리).
- **초상**: 좌측 72~96px, **절차 도트 스프라이트 재활용**(atlas의 동료·각료·아바타 렌더를 4배 확대, image-rendering: pixelated). 외부 이미지 에셋 불필요 — 잼 일정에 결정적.
- **타자기**: 18ms/자. 클릭·E·Space = 즉시 완성 → 한 번 더 = 다음 줄. 우하단 `--gold` ▼ 0.8s 깜박(다음 있음 표시).
- **선택지**: 본문 아래 가로 버튼(기존 .btn 재활용), 숫자키 1~4 대응. 선택 결과는 기존 명령 화이트리스트로만 서버 전송.
- **API**: `GM.dialogue.open({speaker, portraitKey, lines:[...], choices:[{label, cmd?}]})` — 클라 모듈 `public/js/dialogue.js` 신설.
- **잼 범위 연결점**(서버 무변경): 동료 클릭(crewpanel 인사말)·각료 대화(hud 말풍선의 긴 버전)·감정의 날 tagStories(§17-18 모달 대체)·타국 방문 인사(diplomacy 모달 도입부).
- **잼후 연결점**: §18-3 사슬 조사·§18-5 미시 발견의 표준 출력 창구.
- ESC 닫기, cutscene과 z-index 분리, 전투 경보 시 자동 닫힘.

## §18-7. 구현 배치 매핑

| 범위 | 내용 |
