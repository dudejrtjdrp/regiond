# 에셋 교체 배치 계획 v1

작성 2026-08-07 · 전수 목록 정본은 `docs/에셋_명세와_AI툴_가이드.md`(약 1,400~1,650장), 이 문서는 그중 **교체 순서와 생성 단위**를 정한다. 실행은 `python tools\pipeline\run_batch.py tools\pipeline\batches\<파일>.json`.

## 원칙

- **배치1(스타일 프로브)이 PASS 되기 전에는 배치2 이후를 시작하지 않는다.** 기준 캐릭터가 스타일 원기이고, 프로브 8종이 재질 전 계열(피부·천·목재·석재·금속·식생·지형)을 커버한다.
- 배치가 끝날 때마다 Asset Museum에서 검수 → 사이즈 조정 JSON을 Claude에게 전달 → 다음 배치.
- 애니메이션(걷기·공격 시트)과 오토타일 전이는 정지 스프라이트 스타일 확정 후 별도 트랙(후술).

## 배치 2 — 세계의 바닥과 뼈대 (~46종) — 프로브 통과 후 명세 작성

지형 7종×4변주(28): grass·forest·rock·water·fertile·snow·jungle / 자원 노드: forest(벌목)·rock·berry·iron·ruin·cache·oil / 상위 건물 12종 1티어: campfire(본부)·tent·hut·house·storage_crate·well·granary·sawmill·quarry_camp·fence·gate·watchpost

## 배치 3 — 살아있는 것들 (~30종)

웨이브 적 6: wolf(완)·bandit·pirate·viking·ogre·dragon / 야생 12: chicken·rabbit·sheep·pig·cow·deer·boar·stray_dog·bear·bandit_scout·direwolf(+wolf 재사용) / 주민 직업 대표 3(farm·lumber·build) + 상인·병사 NPC / 각료 초상 6은 portrait 워크플로우로 후순위

## 배치 5 — 완성도 (~40종)

이펙트(슬래시·링·먼지·파편) / 유물 대표 12 → 나머지 38 / 유적 카드 12 / 건물 2~4티어 확장 / 장식 4종 / 마차·캐러밴·영토 말뚝

## 별도 트랙 (스타일 확정 후)

1. **캐릭터 애니메이션**: 정지 스프라이트를 원기로 프레임 생성 → `--sheet` 패킹. 아바타는 레이어+팔레트 스왑 구조라 베이스/머리/의상 분리 생성 필요 — 파이프라인 확장 배치로 진행.
2. **오토타일**: 타일 4변주 확정 후 47-blob 전이 세트.
3. **게임 본편 고해상도 렌더 개편**: 마스터 64px/타일 소비. 배치 2 완료 시점에 착수 권장(지형+건물이 있어야 체감 검증 가능).

## 실행 방법

```
:: 배치 실행 (ComfyUI 켜둔 상태에서)
python tools\pipeline\run_batch.py tools\pipeline\batches\batch1_probe.json
:: 특정 에셋만 다시
python tools\pipeline\run_batch.py tools\pipeline\batches\batch1_probe.json --only player/hero_base --force
```
완료 후 `npm start` → `localhost:3000/museum.html` 에서 QA·비교 검수.
