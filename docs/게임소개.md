# 게임 소개 및 설명 — 갈래말래 (가제)

## 개요
마차가 멈춘 자리에 모닥불 하나. 주민은 0명이고, 손에 든 것은 사흘치 곡물과 돌멩이 몇 개뿐이다.
직접 도끼질을 해서 천막을 세우고, 사람이 하나둘 걸어 들어오고, 정착지가 자랄수록 땅이 넓어지고 새 건물이 열린다.
**끝은 없다.** 1~5인이 초대 코드 하나로 같은 정착지를 함께 굴리는 **엔드리스 정착지 성장 · 타워디펜스 웹게임**.
브라우저에서 설치 없이 실행된다.

- 무대: **256×256 공유 월드**. 전장의 안개를 밀어내며 숲·바위·물가·철광·유적을 찾아 나간다
- 코어 루프: **직접 노동(스윙) → 건물 → 주민 유입 → 티어업 → 넓어진 땅 → 더 센 웨이브 → 다시 직접 노동**
- 손맛: 액션은 **스윙 단위**다. 누르고 있으면 서버 쿨타임에 맞춰 도끼가 이어지고, 파편이 튀고, 자원이 아크를 그리며 자원칸으로 빨려 들어간다
- 성장 훅: **티어업이 큰 이벤트** — 팡파레와 함께 영토 말뚝이 새 반경으로 박히고, 새 건물이 도감 카드로 펼쳐진다
- 정보 훅: **감정의 날** — 시간이 아니라 **감정소를 세우고 [땅을 감정한다]를 누르는 것**으로만 열린다. 땅의 내력(태그)과 지하 자원이 드러나고 **관제 선포**로 여섯 자리가 갈린다
- 길잡이: **목표 카드는 언제나 한 장**이고, 그 카드가 **가리킨다** — 대상 위 「E — 나무 베기」 라벨, 월드 화살표, 화면 밖 가장자리 화살표, 카드를 누르면 카메라 점프
- 멀티 훅: **초대 코드 하나로 한 정착지를 함께** — 같이 도끼질하고, 남의 스윙이 화면에 보이고, 창고를 나눠 쓴다

## 실행 방법
```bash
npm install       # Node 22 이상. 외부 빌드 스텝·CDN 없음
npm start         # http://localhost:3000
```

브라우저를 열면 **타이틀 화면**이다.

| 단추 | 하는 일 |
|---|---|
| **[새 정착지]** | 이름 → **난이도 3택**(이야기 / 왕국 / 시련) → **캐릭터 생성**(피부6 · 머리8 · 머리색10 · 의상6 · 의상색10) → **[마차에 오른다]** |
| **[초대 코드로 참여]** | 친구가 알려 준 초대 코드를 붙여 넣어 **같은 정착지**에 들어간다 (1~5인 협동) |
| **[이어하기]** | 저장된 정착지를 잇는다 |

- **역할은 시작 화면에서 고르지 않는다.** 야영지에는 각료가 없다 — **6장에서 감정소를 세우고 [땅을 감정한다]** 를 눌러야 **관제 선포**로 자리가 갈린다.
- 내 초대 코드는 게임 화면 좌상단에서 복사한다. 접속자 명부·대화창은 `M`.
- 서버 없이 화면만 둘러보기: `http://localhost:3000/?mock=1` (구경 모드)
- 같은 땅을 다시 받기: `http://localhost:3000/?seed=20260804`
- 개발 패널은 **Ctrl + `** — 하루 길이(배속)·멈춤·하루 진행·씨앗 지정
- 검증: `npm test`(135개) · `npm run harness`(20항목 — **마커만 보고 1장→6장**) · `npm run smoke`(실브라우저 68항목) · `npm run simulate`(체크포인트 4/4)

## 플레이 흐름 (1게임일 = 실시간 10분, 끝은 없다)
1. **마차에서 내린다** — 자막 넉 줄(언제든 건너뛴다). 모닥불 하나, 주민 0, **목재 0**.
   화면에는 자원 3칸과 목표 카드뿐이다.
2. **첫 손** — 나무 곁으로 걸어가 누르고 있으면 도끼질이 이어진다. **한 그루(3스윙) = 목재 13**, 곧 **천막 한 채(10)**.
   식량은 두 갈래다: 기름진 땅·밭은 **여물어야** 거두고, **물가는 언제든 건진다(어로)** — 대신 물고기는 유한하고 며칠에 걸쳐 다시 몰려온다.
3. **첫 주민** — 오두막을 세우고 곡물이 넉넉하면 사람이 **걸어 들어온다**(이름·외형이 붙는다). 잠자리 = 천막1·오두막2·가옥4·저택6.
4. **땅의 비밀(6장)** — 바위를 캐 **감정소**(목재 60·석재 30)를 세우고, 그 건물을 눌러 **[땅을 감정한다]**.
   컷신과 함께 땅의 내력(태그: 강점+약점)과 지하 자원(철광맥·유막)이 드러나고,
   **관제 선포**에서 여섯 자리 중 하나를 맡는다. 여기서부터 부처 산출·조언이 돈다.
5. **낯선 발자국(7장)** — 안개 속 흔적을 살피러 나간 뒤에야 위협 배지가 켜지고, **웨이브가 4~6일 간격으로 끝없이** 온다.
   늑대 떼 → 도적 → 해적 → 바이킹 → 오우거 → 드래곤 로테이션, 파워 = 560 × 1.07ⁿ × 난이도 × 규모 보정.
6. **읍 이상** — 국법(IF/THEN 논리 회로)을 적어 두면 접속하지 않아도 섭정이 그대로 굴린다.
   7일마다 어전 회의 → 보류 결정 처리 → 유물 상자(50종, 등급 4단계).
7. **웨이브 당일** — 적이 걸어와 울타리를 두드리고, 화살탑·노포·화포가 쏘고, 민병이 붙고,
   **직접 검을 들고 붙어도 된다**(적 곁에서 누르고 있기). **죽지 않는다** — 쓰러지면 모닥불에서 다시 일어난다.
   져도 전멸은 없다: 건물이 상하고(수리 가능) 자원을 빼앗기고 사기가 꺾일 뿐이다.
8. **시즌 종료는 없다.** 지나온 길은 **연대기**(`L`)에 쌓인다.

## 기술 요약
- 서버 권위 + **세 개의 시계**: 일 틱(경제 정산, 600초) / 실시간(스윙·아바타 이동, 즉시) / 서브틱(웨이브 전투 0.25초)
- **실시간 명령은 상태 전량 방송을 하지 않는다.** ack 가 제 결과를 데리고 온다 —
  스윙 ack에는 창고 잔고·노드 잔량·공사 진척이, 아바타 이동에는 **방금 밝아진 안개와 그 안의 노드**가 실린다
- 클라: 바닐라 JS 클래식 스크립트(`GM` 네임스페이스), CDN 없음. 단일 월드 캔버스 + 절차 생성 도트 스프라이트·아이콘·효과음.
  외부 에셋은 한글 도트 폰트(SIL OFL) 하나뿐
- 경제: 콥-더글러스 산출, 재고 기반 로컬 가격(0.30~4.00 클램프), 무역 실효가(관세×운임×정보손실) — 공식과 계수는 v1.1 이래 그대로다
- 전투: 결정론 서브틱 실시뮬(적 이동·터렛 사격·민병·플레이어) + 리플레이 타임라인
- 공간: **256×256** 지형 RLE + 청크(16×16) 안개 diff. 안개는 **걸어 들어간 그 자리에서** 갱신된다.
  노드 뷰는 기본값 항목을 빼고 보낸다(전면 탐사 스냅샷 584KB → 363KB, 평시 변경분 1KB 미만)
- 진행: **진행 감독**(`server/engine/progression.js`) 하나가 건물·기능·UI·명령·이벤트의 모든 문을 쥔다.
  사슬 정본은 `data/chapters.json` — 조건도 해금도 보상도 전부 자료 파일이다
- 정보 비대칭은 **서버에서 강제**한다 (웨이브 날짜·적 병력·인접 보너스·미탐사 노드는 자격이 있어야 페이로드에 실린다)
- AI 3계층: 판단(서버 로직) / 표현(템플릿, API 키 있으면 LLM) / 검증(무인 시뮬 + jsdom 하니스 + 실브라우저 스모크)
- 모든 밸런스 수치는 `data/*.json` 다이얼 — 코드에 매직넘버 없음
