# 오픈월드 RTS 전환 설계 v1.0

사용자 지시: "8×8 격자가 아니라 스타크래프트·워크래프트·심즈처럼 — 넓은 오픈월드에서 내가 직접 백성을 조작하고 움직이고 배치하고 싶다."
전략: **경제·전투·역할·유물·난이도 등 검증된 매크로 엔진은 전부 유지**하고, 공간 계층(맵·타일·배치)만 연속 월드로 교체한다. 매크로 수치는 월드에서 파생된 입력(배치 인원 비율)으로 굴러간다.

## 1. 월드 구조
- **하나의 공유 월드 128×128 타일** (per game). 플레이어 도읍은 중앙 부근, AI 3국 도읍은 세 모서리 방향에 프리셋 마을(정적 레이아웃)로 존재. 무역 마차가 도읍 사이를 오간다(연출) — "세계 뷰" 탭은 폐지되고 월드 그 자체가 세계
- 지형: 풀밭/숲(나무 군락)/바위 노두(석재)/철광맥(태그 보유국 인근)/유막(유전 태그국 인근만)/물/기름진 땅/고대 유적. 시드 기반 생성(재현 가능), 도읍 주변은 시작 자원 보장 배치
- **전장의 안개**: 미탐사(검정) / 탐사됨(어둡게, 정적 정보만) / 시야(밝음 — 백성·건물 주변 반경). 탐사가 곧 오픈월드 재미 — 지도 대부분이 처음엔 검다
- **영토(개척령 연계)**: 도읍 중심 반경 — 1단계 r=10, 2단계 r=14, 3단계 r=18 (기존 expansion.json 단계·비용 재사용, 64→100→144 대신 반경으로). 영토 안에서만 건설·채집 지정 가능. 탐사는 영토 밖 어디든 가능
- 감정의 날: 영토 내 지하 자원(철광맥 등)이 안개 걷히듯 드러나는 연출로 재해석

## 2. 백성(유닛) 직접 조작 — RTS 코어
- 인구는 매크로 수치(50~260) 유지. 화면에는 **대표 백성 유닛 최대 60명**(1유닛≈인구 N명, 비율 자동)이 걸어다닌다
- **선택**: 클릭 단일 선택 / 드래그 박스 다중 선택 / 더블클릭 같은 직업 전체. 선택 시 초상+인원 패널
- **명령(우클릭)**: 자원 노드 → 그 일에 배치(나무=벌목, 바위=채석, 철광=광부, 밭=농사, 유적=탐사, 건설 현장=건설, 성벽=수비) / 빈 땅 → 이동·대기 / 안개 → 정찰(스카우트 이동, 시야 개척)
- **노동 배분 = 배치의 파생값**: 부처별 배분 %는 이제 슬라이더가 아니라 "그 일에 배치된 백성 비율"에서 매 틱 자동 산출 (서버 권위). [각료에게 맡기기] = 추천 배분대로 서버가 자동 재배치. 격려 순행 등 AP 액션은 월드의 유닛/건물 클릭으로 발동
- 이동·애니메이션은 클라 연출(경로는 단순 직선+장애물 회피 정도, A* 풀구현 불요). **서버는 "누가 어떤 노드에 배치됐나"만 권위 관리** — 판정에 위치 픽셀은 안 쓴다

## 3. 건물 자유 배치 (심즈/워크래프트)
- 건설 메뉴에서 건물 선택 → 고스트 미리보기(초록/빨강 유효성) → 영토 내 클릭 배치 → 건설 현장 생김 → 건설 백성이 걸어가 짓는다
- 배치 보너스(기존 인접 보너스의 월드화): 곡창-밭 인접 +, 제련소-철광 인접 +, 항만-물가 등. 유효 반경 안 노드 수로 계산 (건축가 재임 시만 — 정보 비대칭 유지)
- 밭은 값싼 "개간" (목재 소량)으로 영토 내 아무 풀밭에 만든다. 수확 반짝임 클릭(기존 §C-2)은 월드의 밭에서
- **성벽**: 도읍 반경 성곽 링으로 자동 시각화(티어별 외형). 세그먼트 3구간(전술 배분 UI와 연결)이 실제 성곽 위에 표시
- 자원 노드는 채취하면 시각적으로 감소·고갈(숲이 옅어짐, 재생 있음 — 대삼림 태그는 재생 빠름). 고갈 임박 시 백성이 자동으로 근처 다른 노드로 옮김

## 4. 침공의 월드 연출
- D-3: 맵 가장자리에 적 선발대 캠프가 안개 밖에서 목격됨(정찰 보내면 규모 힌트 — 국방부 정보와 연동)
- D-0: 적 부대가 행군해 성곽으로 진격 → 성벽 앞 전투 연출(유닛들 충돌 애니) → 기존 로지스틱+전술 판정 결과가 전투의 승패로 표현 → 승리 시 적 궤주, 패배 시 일부 건물 불탐 연출
- 작전 회의(전술 3택+서지 3구간)는 성곽 구간을 월드에서 직접 클릭해 배분

## 5. 매크로 엔진 접합 규칙 (깨지면 안 되는 것)
- 콥더글러스·가격·무역·전투 공식 **무수정**. laborAlloc은 배치 파생값으로 대체 입력
- 목재·석재 채집: 인구당 계수는 유지하되 "배치된 채집 유닛 비율"로 스케일 — 아무도 벌목 배치 안 하면 0 (기존: 전인구 자동). 기본값 보정: 새 게임 시작 시 백성이 자동으로 근처 숲·바위에 초기 배치돼 있음(방치해도 굴러감 — 섭정 원칙)
- 시뮬레이터·정책 봇: 좌표 없이 "비율 배치 API"로 동일 동작 → 체크포인트 6/6 유지가 합격선
- 타일 기여(§B-2): "지정 타일 수" → "가동 중인 밭/벌목/채석 노드 수"로 자연 이관 (상한 +20% 동일)

## 6. 성능·기술
- 렌더: 단일 캔버스, 카메라(WASD/방향키/가장자리/미니맵 클릭/휠 줌 16·24·32px), 보이는 청크만 그리기, 스프라이트 아틀라스(도트 절차 생성 1회 캐시), rAF 고정스텝
- 유닛 60 + 마차 + 적 부대 수준이라 성능 여유 큼. requestAnimationFrame과 게임 틱(30초) 분리
- 미니맵: 우하단, 안개·영토 경계·침공 화살표 표시

## 7. 프로토콜 v2 (서버 구현 후 PROTOCOL.md 정본화)
- 월드 스냅샷: `world {size, seed, chunks|RLE terrain, nodes:[{id,type,x,y,richness,depleted}], towns, fogMask(자국)}` — join 시 1회 + 변경분 diff
- 백성: `villagers:[{id,job,x,y,targetNodeId,selectedable}]` (틱마다 배치·직업만 갱신, 이동 연출은 클라)
- C→S: `commandVillagers {ids:[], order:{type:'work'|'move'|'scout', nodeId?|x,y}}` / `placeBuilding {key,x,y}` / `reclaimField {x,y}` / `setWallFocus {segments:[3]}` (기존 setBattlePlan 유지) / assignTile·타일 idx 계열은 **폐기**
- S→C: `worldDiff`, `combatScene {units,phases}` (침공 연출 데이터)
- 기존 이벤트(각료·무역·국법·유물·AP·난이도·조언)는 전부 유지

## 8. 구현 순서
1. 서버: 월드 생성·노드·안개·배치 권위·파생 laborAlloc·프로토콜 v2·시뮬 봇 이관 → 테스트/시뮬 6/6
2. 클라: RTS 렌더러·조작(선택/명령/배치/카메라/미니맵)·침공 연출 — 기존 HUD·각료 모달·목표 카드·건국 화면(난이도 선택 추가)은 유지하며 맵만 교체
3. 통합: E2E·하니스 시나리오를 월드 조작 기준으로 재작성

## 9. 역할 선택 시점 변경 (사용자 지시 2026-08-03)
- **건국 화면에서 역할을 고르지 않는다.** 건국 = 왕국 이름 + 난이도 + 보조 옵션만
- 1막(감정의 날 전): 전원 무역할. 백성 조작·채집·건설만 (원 기획 §5-2 그대로)
- **감정의 날 직후 "관제 선포" 화면**: 태그 공개 연출에 이어 역할 선택 — 싱글: 플레이어가 자기 역할 1개 선택 + NPC 위임 4 + 공석 1 구성(성녀 트레이드오프 경고 이 시점에). 멀티: 각 접속자가 각자 고름(중복 시 안내), 남는 자리는 NPC/공석
- 서버: join에서 role 제거 가능해야 함(이미 pickRole 지원). delegate도 감정의 날 이후에만 유효하도록. 전직(숙련 50% 상실+7틱 인수인계)은 기존 규칙 유지

## 10. 군주 아바타 (스타듀밸리·굶지마 레퍼런스, 사용자 지시)
- 플레이어는 **자기 캐릭터(군주)를 직접 조작**한다: WASD/방향키 + 클릭 이동. 백성 RTS 조작과 공존 (심즈+워크래프트+스타듀 하이브리드)
- 아바타 상호작용(가까이 가서 E 또는 클릭):
  - 나무·바위·밭에서 **몸소 일하기** (기존 AP 액션의 월드화 — 도끼질 애니+자원 튀는 연출)
  - 유적 조사(탐사 게이지), 백성에게 다가가 **격려**(주변 오라 버프 = 격려 순행), 상인 마차와 대화(거래 바로가기)
  - 수확 준비된 밭 클릭 수확(§C-2)
- **탐사는 아바타로**: 군주의 시야 반경이 가장 넓다. 안개 속을 직접 걸어 들어가 지도를 밝히는 게 굶지마식 탐험 루프. 위험 요소(늑대 등 소형 야수 — 체력 없이 "쫓겨남+사기 소폭 하락" 수준의 가벼운 페널티)로 긴장만 첨가
- 낮·밤 톤 사이클(코스메틱 조명 그라데이션, 1틱=1일과 동기). 밤엔 시야 소폭 감소 — 굶지마의 무드만 차용, 생존 시스템은 없음
- 아바타 위치는 클라 관리(연출), **행동 판정은 서버**(AP·쿨다운·노드 유효성 검증) — 기존 apAction 계약 재사용(nodeId 기반)
- 멀티: 접속자마다 아바타 1개, 서로 보임(위치 브로드캐스트, 저빈도)

## 11. 타워디펜스 — 터렛 시스템 (사용자 지시)
- 국방 컨텐츠를 타워디펜스화: **터렛을 종류별로 설치**해 침공을 막는다. 성곽 링 세그먼트(3구간) 위·영토 내 요충지에 설치
| 터렛 | 비용 | 기본 전투력 | 상성(×1.5) | 비고 |
|---|---|---|---|---|
| 화살탑 | 목재60·석재30 | +15 | 해적 | 값싸고 다수 배치 |
| 노포 | 목재80·강재20 | +25 | 드래곤 | 관통 대형 특화 |
| 화포 | 강재40·골드80·원유3 | +40 | 바이킹 | 원유 필요 — 무역 사슬과 연결 |
- 설치 상한: 성벽 T0 2기 / T1 3기 / T2 5기 / T3 8기 (다이얼). 국방부 재임: 설치 비용 -20%, 터렛 전투력 +10%
- **판정 접합**: 터렛 전투력은 기존 로지스틱 총전투력에 가산 + 상성 배수 + **피격 세그먼트 배치 시 1.25×**(약점 정보 활용처). 승패는 기존 공식 유지, 전투 연출은 터렛이 실제로 쏘고 적이 쓰러지는 TD 리플레이(combatScene 확장: 발사·명중·처치 타임라인, 결과와 정합하게 생성)
- **밸런스**: 봇 기준 플레이에 터렛 구매 포함시키고 적 공격력 다이얼 재조정으로 체크포인트 6/6 유지 (조정 근거 기록). 터렛은 골드·강재의 새 소비처 — "다 살 수는 없다" 선택압 강화

## 12. 캐릭터 생성 + 멀티플레이 중심 (사용자 지시)
- **이 게임은 멀티플레이 위주다.** 한 국가 1~5인 협동이 기본 시나리오
- **캐릭터 커스터마이징** (건국/입장 시): 피부색 6종 · 머리 모양 8종 · 머리 색 10종 · 의상 6종 · 의상 색 10종 — 절차 도트 스프라이트 레이어 합성(에셋 파일 없이 팔레트 스왑). appearance 객체를 서버가 저장·중계, 모든 아바타·명부·채팅에 반영. 머리 위 이름표
- 멀티 편의: 초대 코드(gameId) 복사 UI, 접속자 명부(아바타 미니 초상+역할+온라인), **간단 채팅**(`chat {text}` 릴레이 + 말풍선/로그), 서로의 군주 아바타가 월드에 보임(위치 저빈도 중계 — 기존 lordMove)
- 역할 선택(감정의 날 후)은 멀티에서 각자 고름 — 중복 시 안내 UX

## 13. 직접 플레이 밀도 상향 (사용자 지시 — "텍스트 게임 같다" 해소)
- **몸소 일하기 AP 폐지**: 아바타로 나무·바위·밭에 가서 일하는 건 **무제한**, 대신 하루 수확 체감 곡선(5회까지 100%, 이후 절반씩, 하한 20% — 다이얼). 클릭할수록 자원이 튀는 손맛이 상시 제공
- AP 3은 큰 액션 전용 유지: 격려 순행(부처 버프) · 유적 탐사 가속
- **재배 루프(스타듀)**: 개간(빈 풀밭→밭) → 자동 파종 → 성장 단계 스프라이트(새싹→성장→황금) → 익으면 반짝 → 아바타/클릭 수확(보너스) → 재파종 자동. 밭 하나하나가 만질 수 있는 오브젝트
- **건설 현장 상호작용**: 아바타가 현장에서 일하면 건설 포인트 가속(+10%/일, 1회)
- 백성 RTS 배치(§2)와 아바타 노동(스타듀)이 동시에 굴러가는 게 이 게임의 조작 정체성: "지시하거나, 몸소 하거나"

## 14. 정정 — 전 건물 직접 배치 (사용자 지시 2026-08-03 2차)
- "타워디펜스"의 의도 = **스타크래프트처럼 모든 건물을 플레이어가 직접 자리를 정해 배치**하는 것. 터렛은 그중 "공격형 건물" 카테고리

- 터렛은 성곽 세그먼트 스냅 외에 **영토 내 자유 배치 허용**(이미 지원) — 세그먼트 위 설치에만 피격 구간 1.25× 유지
