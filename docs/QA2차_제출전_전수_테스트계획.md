# Regiond — 제출 전 전수 테스트 계획 (QA 2차)

**작성 2026-08-08 · 대상 HEAD `b4c2cff` + 에셋/렌더 워킹트리 · 테스트 환경: 배포 서버(Render/Railway)**
목적은 「버그를 다 잡는다」가 아니라 **내일 심사위원이 눌러 볼 자리에 구멍이 없다**를 확인하는 것이다.

---

## 0. 시작하기 전에

### 0-1. 준비물

| 항목 | 내용 |
|---|---|
| 접속 주소 | 배포 URL (성효가 공유). 구경 모드는 `<URL>/?mock=1`, 같은 땅 다시 받기는 `<URL>/?seed=20260804` |
| 브라우저 | **크롬 최신 1개 + 다른 것 1개**(엣지·사파리·모바일 크롬 중 아무거나). 시크릿 창 = 다른 사람 취급 |
| 인원 | 최소 2명 동시 접속 구간이 있다(파트 R). 3명이면 더 좋다 |
| 기록 | 아래 §0-5 버그 리포트 양식. **스크린샷 또는 화면녹화가 없는 제보는 재현이 거의 안 된다** |
| 시간 | 전수 = 1인 3~4시간. 3명이 파트를 나누면 1.5시간 (§0-3 분담표) |

### 0-2. 배포 서버에서만 생기는 성질 — 버그로 오해하지 말 것

- **15분간 아무도 안 들어오면 서버가 잔다.** 그 뒤 첫 접속은 30초쯤 화면이 「땅을 살피는 중…」에 머문다. → **정상**
- **서버가 재시작되면 세이브가 사라진다**(무료 플랜은 디스크가 휘발성). [이어하기] 목록이 비는 건 정상일 수 있다
- **`Ctrl + \`` 개발 패널이 안 열린다** — 운영 배포에서는 잠긴다(`/api/debug/*` 가 404). → **정상**
- 하루 = 실시간 10분. **개발 패널이 없으므로 하루를 건너뛸 수 없다.** 후반 콘텐츠(웨이브·무역·엔딩)까지 보려면 시간이 걸린다
  → 후반 파트(L·N·O·P·Q)는 **한 명이 긴 판을 잡고 계속 굴리는 방식**으로 맡는 게 효율적이다

### 0-3. 파트 분담 제안 (3인 기준)

| 담당 | 파트 | 대략 시간 |
|---|---|---|
| **A조 — 첫인상·튜토리얼** | A, B, C, D, E, F | 1~1.5시간. 심사위원이 실제로 볼 구간이라 가장 중요 |
| **B조 — 중반 시스템** | G, H, I, J, K, M, N | 1~1.5시간. 새 판을 잡고 6~9장까지 밀어붙인다 |
| **C조 — 후반·멀티·환경** | L, O, P, Q, R, S, T, U, V | 1~1.5시간. **R(멀티)은 A조·B조와 시간 맞춰 함께** |

> 셋 다 **다른 시드/다른 판**으로 시작할 것. 같은 땅만 보면 지도 탓 버그가 안 드러난다.

### 0-4. 우선순위 표기

- `P0` — **깨지면 제출이 곤란하다.** 첫 30분·멀티 동기화·크래시·진행 막힘
- `P1` — 기능이 죽어 있음. 있어야 할 것이 없거나 반응이 없음
- `P2` — 어색함·오탈자·연출 부재. 잼 후로 미뤄도 되는 것

### 0-5. 버그 리포트 양식 (이대로 복사해서 쓰기)

```
[ID]        A-07
[우선순위]   P0 / P1 / P2
[환경]      크롬 / 엣지 / 모바일  ·  배포 / 로컬  ·  혼자 / 2인
[시드·판]    seed=... (모르면 「모름」)  ·  게임 몇 일차
[재현 절차]  1) ... 2) ... 3) ...
[기대]      ...
[실제]      ...
[재현율]    3번 중 3번 / 1번
[첨부]      스크린샷·녹화·(F12 콘솔의 빨간 줄 복사)
```

> **F12 → Console 탭을 켜 두고 플레이할 것.** 빨간 에러 한 줄이 재현 절차 열 줄보다 값지다.

### 0-6. 이미 알고 있는 것 — **제보하지 않아도 된다**

| 증상 | 상태 |
|---|---|
| 고기·가죽·털·장화 아이콘이 **돌멩이 모양**으로 나온다 | 알려짐 (`icons.js` 폴백) |
| 감정소·개척 깃발·목장 스프라이트가 밋밋하다 | 알려짐 (`atlas.js` STYLE 누락) |
| **배치대 생산 갈래에 목장(ranch)이 안 보인다** | 알려짐 (`buildings.json` production.order 누락) |
| 적·야생짐승이 때릴 때 **공격 모션이 없다** / 쓰러진 아바타가 **서 있는 자세** | 알려짐 (에셋 미완) |
| 기차 정거장에 닿아도 **저절로 안 내려진다** | 알려짐 (건물 위 이동 차단의 회귀) |
| 티어 7 이상이 안 열린다 / 인구 100을 못 넘는다 | 알려짐 (도달 곡선 과제, 잼 후) |
| `/museum.html`, `/building-lab.html` | **개발용 에셋 검수 페이지**다. 게임과 무관 — 테스트 대상 아님 |

**반대로, 위 목록에 없는 것은 아무리 사소해도 적어 주세요.**
