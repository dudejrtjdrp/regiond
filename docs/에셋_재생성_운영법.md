# Toji 에셋 전면 재생성 운영법

기존 생성본의 품질이 낮아도, 배치 원본에 들어 있는 모든 에셋은 다시 생성한다. 단, 사람이 명시적으로 제외한 ID만 재생성하지 않는다.

## 1. 제외할 에셋 지정

`tools/pipeline/excluded_assets.json`의 `exclude` 배열에 에셋 ID를 넣는다.

```json
{
  "exclude": [
    "building/hut",
    "tree/oak_large",
    "ui/heart"
  ]
}
```

이 목록은 기존 이미지 파일·manifest 등록 여부와 무관하다. `--force`를 사용해도 목록에 있는 ID는 건너뛴다.

## 2. 전체 재생성

ComfyUI를 실행한 뒤 프로젝트 루트에서 다음을 실행한다.

```bat
tools\pipeline\regen_overnight.bat
```

이 스크립트는 노드/식생, 광물, 나무, 건물, 연결 구조물, 아이템, 장비, UI, 이펙트를 모두 `--force`로 재생성하고, 제외 장부를 적용한다. `batch1`에만 있는 오두막·참나무·바위 노드와 기본 장비/재료도 선택 실행으로 포함한다.

타일셋·플레이어·NPC·몬스터 같은 캐릭터 계열은 이번 범위에서 제외한다. 또한 연결 구조물 배치에 섞여 있는 길·앞마당 타일도 자동으로 건너뛴다.

## 3. 특정 배치 또는 특정 에셋만 재생성

```powershell
python tools/pipeline/run_batch.py tools/pipeline/batches/batch4_buildings.json --force --exclude-file tools/pipeline/excluded_assets.json
python tools/pipeline/run_batch.py tools/pipeline/batches/batch4_buildings.json --only building/smithy,building/mill --force --exclude-file tools/pipeline/excluded_assets.json
```

## 4. 프롬프트의 정본

각 에셋은 배치 JSON 안에 독립된 `desc`를 가진다. 공통 프롬프트를 재활용하지 않으며, `generate.py`가 이 설명에 카테고리별 렌더링 계약만 덧붙인다.

- 건물: `tools/pipeline/batches/batch4_buildings.json`
- 나무·식물·광물: `tools/pipeline/batches/batch3_nodes_flora.json`
- UI: `tools/pipeline/batches/batch8_ui.json`

생성 후에는 `/museum.html`에서 후보를 검수하고, 새 결과가 QA를 통과했을 때만 기존 `base.png`와 manifest 항목을 교체한다. 모든 후보가 실패하면 기존 발행본은 보존된다.
