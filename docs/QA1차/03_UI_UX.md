# 03 UI/UX

## 버그
### B03-1 공장장 UI 무반응 (P1)
- 증상: 공장장 창에 강재·연료·무기 항목 옆 검은 기둥 + −/+ 버튼만 있고 설명이 없음. −/+ 눌러도 변화 없음. 뭘 하라는 건지 모름.
- 방향: 원래 의도(생산 비율? 목표 수량?)를 코드에서 확인 → 동작 수리 + 라벨·현재값·효과 설명 표시.
- 수용 기준: 버튼 조작이 실제 생산에 반영되고, 처음 보는 유저가 설명 없이 이해 가능.

### B03-2 상단 자원바에 금 미표시 (P1)
- 수용 기준: 금 보유량이 항상 보임.

### B03-8 타 게임 언급 텍스트 제거 (P1 — 즉시 처리 가능, 공모전 리스크)
- 증상: "스타크래프트같이 멀티" 류 문구 존재.
- 방향: 전체 텍스트 grep으로 타 게임명·상표 전수 제거/치환.

## 기능
### F03-3 지형 진입 연출 (P1)
- 새 지형 입장 시 작은 알림 대신 **화면 중앙에 지형 이름 크게** ("사나운 것들의 땅"). 페이드 인/아웃.

### F03-4 날짜 전환 연출 (P1)
- 다음날이 되면 전환 애니메이션 + **N일차** 를 화면 중앙에 크게.

### F03-5 crew 패널에서 카메라 이동 (P1)
- '함께 다스리는 이들'에서 프로필 클릭 → 그 플레이어에게 카메라 이동.

### F03-6 건물 행동 즉시화 (P1)
- 건물 선택 행동 시 '숨 고르기' 딜레이 제거.
- 건물에서 할 수 있는 행동(예: 손수 제련한다)은 **건물 위에서 E키로 즉시 실행**.

### F03-7 터렛 공격 이펙트 강화 (P1)
- 현재는 공격 중인지도 모름. 발사체/트레이서·명중 이펙트를 뚜렷하게.

### F03-9 오브젝트 스케일 정비 (P2)
- 분수 등 커야 할 것이 작음. 전체 스케일 일람 후 조정(D 배치의 structureRect 1.18배 체계 재활용).

### F03-10 자원 사용처 안내 (P2)
- 금·금화·석탄·석유·연료·고기·가죽·털 등 "어디에 쓰는지 모르겠다" 해소.
- 방향: 자원 툴팁에 사용처 표기 + (07의 사용처 콘텐츠와 세트).
