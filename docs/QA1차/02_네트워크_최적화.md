# 02 네트워크 최적화 — P0

## B02-1 몹·플레이어 이동 끊김/텔레포트
- 증상: 동물·적·플레이어가 전체적으로 뚝뚝 끊기며 이동하거나 텔레포트.
  특히 ① 게임 시작 직후 ② 새 플레이어 입장 직후 심함(봇·초대 유저가 막 순간이동).
- 추정 원인 후보 (구조 분석으로 확정할 것):
  1. 클라 측 위치 보간(interpolation) 부재 또는 스냅 처리 — 틱 간격 그대로 점프.
  2. 입장 시 풀스냅샷 수신 때 엔티티 위치 리셋 → 01의 스냅샷 경로와 연관.
  3. 브로드캐스트 주기가 낮거나 배치 전송 시 타임스탬프 미사용.
- 방향: 서버 틱은 유지하고 **클라 보간 버퍼(수신 시각 기준 100~200ms 지연 렌더)** 도입.
  스냅 거리 임계(순간이동 판정) 초과 시에만 즉시 스냅.
- 수용 기준: 평상시 부드러운 이동, 입장/시작 직후에도 기존 엔티티가 튀지 않음.
- 주의: 결정론 원칙(월드 난수) 침해 금지 — 렌더 계층에서만 해결.
