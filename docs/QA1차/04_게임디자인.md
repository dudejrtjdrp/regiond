# 04 게임디자인 — 진행·장 흐름

## 버그
### B04-1 잠듦 상태가 다음날에도 유지 (P1)
- 수용 기준: 다음날 전환 시 잠듦 해제.

### B04-2 경험치 반영 누락·지연 (P1)
- 증상: 올랐다가 안 올랐다가. 반영이 늦는 경우도.
- 수용 기준: 모든 행동(채집·사냥 등)에 경험치가 즉시·일관되게 반영. (멀티 동기화 01과 연관 여부 확인)

### B04-3 정착지 체력 회복 안 됨 (P1)
- 수용 기준: 정착지(또는 지정 시설) 범위 내에서 회복. 수치는 data/*.json.

## 기능
### F04-4 침공 앞당기기 — "무작정 대기" 제거 (P2 ★유저 이탈 직결)
- 현재: 적이 올 때까지 할 일 없이 대기. 유저는 뭘 하며 기다려야 할지 모름.
- 방향: 군사 탭에 **침공 조건을 명시** (예: 필요 건물 N개 이상·주민 N명 이상 등) →
  조건 도달 시 "다음날 적이 온다" 예고. 즉, 준비를 끝내면 유저가 전투를 앞당길 수 있음.
- 수용 기준: 대기 중에도 화면에서 "다음에 뭘 하면 되는지"가 항상 보임.

### F04-5 웨이브 실패 구제 (P2 ★)
- 현재: 첫 무리를 못 막으면 영원히 7장에 갇힘.
- 방향(택1, 구조 보고 결정): ① 실패해도 페널티(자원·건물 피해)만 받고 장은 진행
  ② 빠른 재정비 후 단축 대기로 재도전.

### F04-6 장 진행 가시화 (P2)
- 현재: 이 장이 언제까지 막힐지 유저가 모름 → 무한 대기 체감.
- 방향: 현재 장의 목표·남은 조건·예상 시점을 상시 노출 (F04-4와 세트).

### F04-7 강재 병목 완화 (P2)
- 현재: 7장에서 막히면 8장을 못 가서 강재를 아예 못 얻음.
- 방향: 화로류 강재 수단을 6장쯤 조기 해금하되 산출 속도를 낮게 (수치는 data, 06과 세트).

### F04-8 장 수 대폭 확장 (P2~3)
- '끝이 없는 길'이 너무 빨리 옴. 장 수를 훨씬 늘림 (07 콘텐츠 확장과 세트로 기획).

### F04-9 멀티 서버 시간 가속 (P2 — 테스트 인프라)
- 현재 개발 패널 가속이 서버(멀티)에서도 동작하게. QA 효율 직결이므로 QA-C에 앞당겨도 좋음.
