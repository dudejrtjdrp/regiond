# 01 멀티플레이 동기화 — 전부 버그, P0

공통 단서: **나갔다가 같은 코드로 재입장하면 전부 해결됨.**
→ 작업 순서: ① server의 모든 `emit` 지점 전수 조사(`socket.emit` vs `io.to(room).emit` vs 콜백 응답)
② 게스트 소켓의 룸 join 시점·유지 확인 ③ 클라가 게스트일 때 스냅샷/증분 적용 경로 확인.
개별 패치 전에 원인을 하나로 좁힌다. 수정 후 아래 전 항목을 2클라로 재검증.

## B01-1 감정소·대화창·역할 선택이 방장에게만 표시
- 증상: 감정소에서 감정하면 원래 모든 플레이어에게 떴는데 지금은 방장에게만. 대화창·역할 고르기도 방장만.
- 수용 기준: 게스트 화면에도 동일 연출·선택 UI 표시(역할 선택은 설계상 누가 고르는지 먼저 확인 — 방장 단독 선택이 의도라면 게스트에겐 관전 표시).

## B01-2 자원 수치 진동 (446 ↔ 31)
- 증상: 곡물·목재·석재 등이 446이었다가 31로 널뛰기. 자원 공유가 안 되는 것처럼 보임.
- 추정: 서로 다른 두 소스(서버 권위 값 ↔ 게스트 로컬/초기값)가 번갈아 렌더됨.
- 수용 기준: 모든 클라에서 자원 수치 동일·단조 변화.

## B01-3 코드 입장 플레이어가 '함께 다스리는 이들' 목록 누락
- 수용 기준: 입장 즉시 모든 클라의 목록에 반영, 퇴장 시 제거.

## B01-4 안개·미니맵 공유 안 됨
- 증상: 팀이 밝힌 곳이 공유됐다가, 내가 그쪽으로 가면 다시 검은색. 예전엔 팀이 간 곳은 안개(회색)였음.
- 추정: 로컬 시야 갱신이 공유 탐사 상태를 덮어씀.
- 수용 기준: 탐사 상태는 팀 단위 합집합, 되돌아가도 유지.

## B01-5 팀원이 캔 자원 노드(궤)가 내 화면에 잔존
- 증상: 팀원이 캐서 없어졌는데 내 눈엔 보이고, 캐면 "그런 자리가 없다".
- 수용 기준: 노드 소멸이 전 클라에 즉시 반영.

## B01-6 쓰러짐·리스폰 상태 미동기화
- 증상: 리스폰했는데 계속 「그대 - 쓰러짐」 표기. 반대로 팀원에게는 쓰러진 상태가 안 보임.
- 수용 기준: 쓰러짐/부활이 본인·팀원 모두에게 즉시 정확히 표시.

## B01-7 재입장 후 외형(옷) 무작위 변경
- 증상: 나갔다 다시 들어와 움직이면 옷이 계속 무작위로 바뀜. E키 상호작용 후엔 멈춘다는 제보.
- 추정: 외형 시드/ID가 재입장 시 재배정되고, 상호작용 시 서버 값으로 고정됨.
- 수용 기준: 외형은 서버 저장값으로 고정, 재입장에도 불변.

## B01-8 플레이어 이름이 '그대'로 표기
- 증상: 설정한 이름 대신 기본 호칭 '그대'가 표시됨.
- 수용 기준: 본인·팀원 화면 모두 설정 이름 표시(연출상 2인칭 '그대'가 필요한 문구는 예외 명시).
