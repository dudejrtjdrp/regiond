# 07 콘텐츠 — P3 (착수 전 세부 기획 재분할)

## F07-1 바이옴 10개 이상 + 지형별 정체성
- 지형(바이옴) 최소 10개. 땅마다 특성(자원·이동·날씨 등)과 **서식 몹 구성이 다르게**.
- §17-17에서 snow/jungle 추가된 체계 위에 확장. F03-3(진입 연출)과 세트.
- 메모리 [[toji-exploration-direction]]의 바이옴 정체성 방향과 합치.

## F07-2 무기·방어구 종류 확대
- 티어·재료(강재 등)별 라인업. 06 수급 곡선과 연동.

## F07-3 적 종류 다양화
- 현재 적 종류가 적음. 바이옴별·장별 적 구성 차등(F07-1과 세트).

## F07-4 용 — 초강력 단일 개체
- 용은 **겁나 세게, 세계에 한 마리만**. 엔드게임 목표/이벤트로.

## F07-5 금화 사용처
- 현재 금·금화를 쓸 곳이 없음. 후보: 무역(F07-7), 용병/특수 주민, 연구 가속, 커스터마이징(F07-9).

## F07-6 부산물 사용처
- 석탄·석유·연료·고기·가죽·털의 소비처 설계 (요리·방한·군수 등). F03-10 툴팁과 세트.

## F07-7 무역 동기
- 현재 무역할 이유가 없음. 국가별 시세 차·특산품·금화 순환의 축으로 재설계.

## F07-8 감정소 규칙 변경
- **한 번만 지을 수 있고, 철거 불가**로.
- 1회 사용 후에도 쓸 일이 있게 — 후보: 주기적 재감정 이벤트, 태그 심화/변이, 순례 방문객.

## F07-9 주민 커스터마이징
- 주민 이름·옷 변경 기능 (B01-7 외형 고정 수리가 전제).
