# 05 AI

## 버그
### B05-1 봇 '알아서 나누기' 시 정착지로 모임 (P1)
- 증상: 자동 배분을 켜면 각자 일하러 가지 않고 정착지에 모여 있음.
- 방향: 자동 배분 후 작업지 할당·이동 로직 확인 (Sprint 2 자동 배치와의 상호작용 의심).
- 수용 기준: 배분 직후 각자 작업지로 이동해 실제 산출 발생.

### B05-2 적이 물에서 스폰돼 갇힘 (P1)
- 수용 기준: 스폰 지점 지형 검사(통행 가능 + 목표까지 경로 존재)로 물/고립 스폰 0건.

## 기능
### F05-3 침공 경로 — 부수며 진입 (P2, 10_전투와 세트)
- 현재: 석벽·울타리 외 건물은 무시하고 정착지 중앙으로 직진.
- 방향: 석벽 → 길목의 건물들을 차례로 부수며 진입. F08-1(건물 체력)이 전제.
- 주의: Sprint 3 예산제 A* 위에서 — 경로 비용에 「부술 수 있는 장애물」 가중치 추가하는 방식 검토.
