# 08 건물

## 버그
### B08-2 매립지 위 건설 불가 (P1)
- 증상: 매립해도 그 땅 위에 건물을 못 지음.
- 수용 기준: 매립 완료 타일은 일반 지면과 동일하게 건설 가능.

## 기능
### F08-1 건물 체력 (P2, F05-3 전제)
- 모든 건물에 체력. 업그레이드 시 체력·내구성 상승. 세이브 호환 주의(기존 세이브의 건물엔 기본값 부여).

### F08-3 터렛·건물 종류 확대 (P3)
- 07 콘텐츠 기획과 세트로.

### F08-4 목장 개편 (P2~3)
- 목장다운 외형(울타리 형태). 완공 후 야생 동물에 Q키 「키우기」 추가(사냥과 병존).

### F08-5 개척 깃발 → 영토 개척 시스템 (P3, 규모 큼 — 별도 기획 필요)
- 깃발 1개 설치 → 그 깃발 중심으로 **울타리 모양 8개 자리** 표시 →
  다른 지형에 8개를 맞춰 세우면 → 8개 중앙에 정착지 건설 가능(대자본 소모).
- 기존 단일 깃발 저장 데이터와의 호환·마이그레이션 설계 필수.
