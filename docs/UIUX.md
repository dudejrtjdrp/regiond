# UI/UX 개편 가이드 v1.0 — "개발 화면"이 아니라 "게임"으로

레퍼런스: **문명**(정보 구조 — 상단 자원 바, 고문, 우측 알림 스택, 툴팁 계층) + **스타듀밸리**(감성 — 따뜻한 색, 두꺼운 픽셀 프레임, 대화 말풍선, 아기자기한 피드백).
기존 다크 개발자 대시보드 톤을 버린다. 서버·PROTOCOL은 손대지 않는다 (뷰 데이터는 이미 충분).

## 0. P0 버그 — 로비 입력·선택 불가
실브라우저에서 이름 입력과 역할 카드 클릭이 안 됨. 유력 원인: 전체화면 배경 캔버스가 폼 위를 덮음(z-index/pointer-events) 또는 오버레이 요소의 클릭 가로채기. jsdom은 레이아웃이 없어 못 잡았음. **CSS 스태킹을 전수 점검**하고, 배경 장식 캔버스는 일괄 `pointer-events:none` + 음수 z-index 원칙으로 고칠 것. 수정 후 elementFromPoint 검증이 안 되는 jsdom 한계를 감안해, 규칙으로 방지: "장식 요소는 반드시 .decor 클래스 + pointer-events:none".

## 1. 다섯 원칙
1. **세계관 언어만 노출.** 부처→각료, 결정 큐→어전 안건, 서지→긴급 동원, 논리 회로→국법(칙령), 오퍼→상인 제안. 금지어(UI 노출 금지): 콥더글러스, O(g), 클램프, R값, 틱, AST, NPC(→각료/백성), 큐, 파라미터
2. **점진 공개.** 1막: 자원 3종(곡물·목재·석재)+타일 지정+목표 카드만. 시장·무역·국법·방어·공장 UI는 감정의 날에 해금(자물쇠 아이콘 → 해금 연출과 함께 등장). 정보 과부하가 "어렵다"의 주범
3. **숫자보다 상태.** 기본 표시는 아이콘+게이지+상태 문구("넉넉함/빠듯함/위험"). 정확 수치·공식은 호버 툴팁 2단계(요약→자세히)
4. **항상 다음 할 일이 보인다.** 좌상단 목표 카드(퀘스트식, 진행바, 완료 시 팡파레). 지금 뭘 해야 하는지 모르는 순간이 없어야 함
5. **만지는 맛.** 모든 버튼 hover 들림+active 눌림, 자원 증감 플로팅 텍스트, 획득 반짝임, 부드러운 패널 전환. (기존 juice 원칙 유지·강화)

## 2. 비주얼 시스템 (스타듀밸리 톤)
- **팔레트**: 양피지 크림(#f4e4bc 계열) 패널 + 진갈색 목재 프레임(#5d4037) + 포인트 골드(#e8a33d)·그린(#6a994e)·레드(#bc4749). 배경(맵 밖)은 짙은 남색 밤하늘+별 도트. 다크 대시보드 회색 전면 제거
- **패널 프레임**: 두꺼운 계단식 픽셀 보더(3~4px, 밝은 모서리/어두운 모서리로 입체감), 모서리 리벳 점, 은은한 드롭섀도. 공용 클래스 `.panel-wood`, `.panel-paper`로 통일
- **폰트**: 한글 도트 폰트 동봉 시도 — Galmuri(https://github.com/quiple/galmuri, OFL) woff2를 public/assets/fonts/에 다운로드해 @font-face로. 네트워크가 막히면 시스템 고딕 + 굵은 웨이트로 폴백 (CDN 런타임 참조는 여전히 금지, 파일 동봉만 허용)
- **아이콘**: 자원 7종+골드+인구+사기+역할 6종을 16×16 도트로 오프스크린 캔버스에 1회 그려 dataURL 캐시 → <img>로 어디서나 재사용. 텍스트 라벨 의존 줄이기
- **커서·사운드**: 클릭 가능한 곳 cursor:pointer 일관 적용. WebAudio 8bit 효과음(클릭/획득/경고/팡파레) + 음소거 토글(기본 켬, 볼륨 낮게)

## 3. 레이아웃 (문명식 정보 구조) — 탭 나열 폐지
```
┌ 상단 자원 바: [아이콘+수량+▲▼일변화] 칩 (곡물·목재·석재·강재·연료·석유·철광·골드·인구·사기)
├ 좌상단: 달력 배지 (N일차/14 + 계절감 아이콘) + 침공 카운트다운 배지(성녀 없으면 "?일 내")
├ 우측 세로: 알림 스택 (어전 안건·상인 제안·완공·경고) — 문명 알림처럼 아이콘 뱃지, 클릭→카드 펼침
├ 중앙: 맵 (국내 ↔ 세계 토글은 맵 좌상단 미니 버튼) — 항상 게임 화면이 주인공
├ 하단 중앙: 컨텍스트 패널 — 선택한 타일/건물/국가의 정보+행동 버튼 (선택 없으면 숨김)
└ 좌하단: 각료 초상 6개 (고문 시스템) — 상태 점(초록/공석 회색/경고 빨강), 클릭→말풍선 보고+그 부처 관리 모달
```
- 관리 화면(노동 배분·공장·건설·무역·국법·유물)은 전부 **각료 초상 또는 알림에서 진입하는 모달**로. "농정관에게 노동 배분을 명한다"는 서사가 생김
- 노동 배분: 슬라이더 대신 **백성 아이콘 드래그 분배**(총원 표시, 부처별 인원 그림) + [각료에게 맡기기]=추천 배분
- 개발 패널(⚙)은 유지하되 기본 숨김 (Ctrl+` 만)

## 4. 화면별 지침
### 로비 → "건국" 2장면
1) 타이틀: 게임 로고(도트 성+깃발 애니), [새 왕국] [이어하기] 두 버튼만. 별 하늘 배경
2) 건국 한 장: 왕국 이름 입력(크게, 자동 포커스) → 역할 6 카드(도트 초상+한 줄 소개+"이런 분께"+난이도 별점) → 하단 [추천 구성으로 시작] 큰 버튼 (기본: 나머지 각료 자동 위임). "직접 꾸리기" 접힘 패널에 위임/공석 편집. 성녀 카드 선택 시 말풍선 경고. **클릭 2번이면 게임 시작**이 목표
### 1막 (튜토리얼)
- 코치마크 3개(첫 진입 1회): ① 맵 타일 클릭→지정 메뉴 ② 자원 바 ③ 목표 카드
- 목표 카드: "밭을 3곳 일구세요" → "곡물 100·목재 100 모으기(진행바)" → "감정의 날을 기다리세요"
- 감정의 날 컷신은 유지하되 종료 후 "새로 열린 것들" 요약 카드(시장·각료·건설 해금 안내)
### 어전 회의 / 안건
- 서신·두루마리 카드 스타일. 각료 초상+타이핑 대사 유지. 선택 버튼 큼직하게+결과 미리보기 한 줄("수락하면: 곡물 -50, 골드 +40")
### 침공
- D-3부터 화면 가장자리 붉은 비네트 서서히+캘린더 배지 펄스. 판정은 연출 모달: 성벽 앞 적 도트 행렬→주사위 굴림 연출→결과. 패배 문구는 기존의 위로 톤 유지
### 세계 뷰
- 지도 질감(양피지) 위 4국. 국가 노드에 국기+표정(관계). 무역로 파티클 유지. 거래 UI는 "상단 회담" 모달(상인 초상+대화형)
### 국법(구 논리 회로)
- "IF/THEN 폼" 표현을 자연어 문장 빌더로: "만약 [곡물]이(가) [100] [이상]이면 → [내다 판다]" 드롭다운 문장. 저장된 국법은 두루마리 목록. 내부 AST는 기존 그대로
### 결산
- 연대기 스타일: 시즌 하이라이트 3~4줄(감정의 날 태그, 침공 결과, 유물) + 순위. [다시 하기]
