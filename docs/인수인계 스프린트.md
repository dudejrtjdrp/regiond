### A-1. worldDiff 진짜 diff화 — ✅ 완료
- **현황**: 이름과 달리 fog 청크·노드에만 diff 가 적용되고 구조물·울타리·주민·캠프·아바타·군락·마을은
  매번 전량 직렬화된다(후반 60~150KB/회). [server/engine/view.js buildWorldDiff]
- **왜 미뤘나**: 클라 병합 계약 확장 + PROTOCOL 판번호 상향이 필요 — 배치 트랙과 충돌 위험.
- **착수 힌트**: 노드가 이미 쓰는 「변경분 + stamp」 패턴을 울타리(hp 변경분만)·주민(residents 는
  state 에만)으로 확장. Sprint 3 이 만든 뷰 공유 캐시(newViewCache)가 절반의 비용은 이미 없앴다 —
  이건 **전송량**의 문제다.

### A-2. battleTick 페이로드 축소 — ✅ 완료
- **현황**: 서브틱(4Hz)마다 적·민병·터렛·플레이어 전량 스냅샷(전투 중 초당 60~160KB/클라).
  [server/engine/battle.js battleSnapshot, server/index.js ~:299]
- **착수 힌트**: 민병·터렛은 변경분만 또는 2Hz 분리. 적 위치는 4Hz 유지(클라 보간 전제 확인).

### A-3. 안개 마스크 Uint8Array화 — ✅ 완료
- **현황**: fog.mask 가 147k 문자열이라 stampVisionDisc 가 이동마다 split('')/join('') — 이동 1회당
  ~30만 요소 할당. [server/engine/fog.js:159-186]
- **왜 미뤘나**: 세이브 포맷 이전(migrateWorld 라인 추가 + world.migrationRev 상향) 동반.
- **착수 힌트**: 마스크를 Uint8Array 로 저장하고 직렬화 때만 문자열/base64 로. exploredRatio 캐시는
  Sprint 3 이 이미 처리(마스크 문자열 identity 비교) — 포맷을 바꾸면 그 캐시 키도 함께 바꿀 것.

- 보상 낱말 둘 추가: `damage`(hp 1 하한) · `villager`(생존자 결말). PROTOCOL **§0-L**.
- 결정론 — 링마다 `statRng('<seed>:trails:ring<n>')`. **언제** 열리든 자리가 같다(회귀로 붙듦).

  발화) · 수집첩. 지금은 셋 다 「사슬의 결말」로만 표현되어 있다.

### C-2. 연구 조기 분기 — 10장 공백의 근본 해법 — ✅ 완료 (2026-08-08, §21-C2)
착수 힌트 두 갈래를 그대로 갔다. PROTOCOL **§0-C** 신설(판번호·세이브 포맷 무변경).
- ① **연구가 4장에 열린다** — chapters.json 4장 `opens` 에 `research`·`panel.research`·`startResearch`.
  새 가지 둘: `tidy_stores`(곳간 정리, 티어1, 곡물 +8%) · `whetstone`(숫돌, 티어2, 목재·석재 +8%).
  **금화 0 · 하루 · 선행 없음** — 값이 아니라 하루를 치르므로 주민을 기다리는 빈손에 정확히 맞는다.
  `research.order` 맨 뒤에 놓았다(order 는 자동 플레이 우선순위 — playtest15c 계약). tiers.json 거울 동반.
- ② **10장은 끝나지 않고 매듭을 짓는다** — ch10 에 `cycle:true` + 칸 둘(`knot_folk` 사람 여섯 ·
  `knot_hold` 무리 둘). 칸을 다 지나면 장을 넘기는 대신 `chapterDone{cycle:n}` 을 내고 첫 칸으로 돌아온다.
  셈은 `since:true` — 「지금까지」가 아니라 **「이 매듭에 들어와서」**(눈금 `progress.mark` 를 매듭마다 다시 찍는다).
  문턱은 `grow`/`growMax` 로 조금씩 오르되 **천장을 둔다** — 없으면 언젠가 아무도 못 짓는 매듭이 온다.
- 검증에서 드러난 것 둘(둘 다 **기존 잠복 결함**, 이 배치가 만든 것이 아니다):
  ① `harness/client_harness.mjs` 의 연구 칸이 「연구 칸이 생겼는가」만 기다렸다 — 연구가 4장에 열리자
  앞 칸의 낡은 판이 그대로 통과했다. 기다릴 것을 「올린 단계·값이 판에 닿았는가」로 바꿨다.
  ② `test/e2e.mjs` 의 `once('avatars')` 가 접속 무렵 방송 무더기의 끝을 안 기다렸다 — payload 가 조금만
  커지면(장 사슬에 칸이 늘자 실제로) 우리가 일으킨 사건 대신 늦게 온 접속 판을 집었다.
  `awaitLatest('worldState')` 로 줄이 끝난 뒤 귀를 열게 했다.
- 남은 자리: 초반 가지를 후반 트리(농정술·석공술)와 선행으로 잇는 것은 **일부러 안 했다** — 자동 플레이
  우선순위와 시드42 밴드를 함께 흔든다. 잇는다면 simulate 재측정을 같은 배치에서 할 것.
