## v3.0 QA 마감에서 고친 것 (2026-08-04)
| 무엇 | 왜 |
|---|---|
| **안개 즉시 공개** | 안개가 일 틱(10분)에만 다시 계산돼 걸어 들어간 땅의 노드가 안 내려왔다 → `lordMove` 가 그 자리에서 시야를 찍고 작은 `worldDiff` 를 흘린다 |
| **어로(물가 스윙)** | 자료 파일끼리 어긋나 물가를 치면 튕겼다 → 어로 규격을 정의(초반 식량 다양화, GDD3 §2) |
| **맨손 시작** | 시작 목재 25 때문에 첫 천막이 도끼질 없이 서 버렸다 → 목재 0 (한 그루 = 천막 한 채) |
| **실시간 ack 의 잔고** | 스윙해도 화면 자원칸이 최대 10분 묵던 사고 → ack 에 권위값을 실어 즉시 반영 |
| **컷신 건너뛰기 가림** | 알림이 [건너뛰기] 단추를 정확히 덮었다 → 시간이 정해진 단추를 알림 위로 |
| **성능 지표·검사 재현성** | 프레임 게이트가 통과 불가 조건이었고 하니스가 매번 다른 땅을 받았다 → 지표 재정의 + 씨앗 고정 |
