# 게임플레이 확장 설계 v1.0 — 난이도 · 영토 개척 · 직접 조작

> **[v2 이관 노트]** 이 문서의 §A(난이도) · §C-1(AP) · §C-3(작전 회의) · §C-4(유적) 규칙은 그대로 살아 있다.
> 다만 **공간 계층은 docs/WORLD.md 로 이관됐다** — §B 의 8×8→10×10→12×12 격자 확장은 '도읍 반경 10→14→18'로,
> §B-2 의 타일 자질·타일 기여는 '월드 자원 노드의 rich 와 가동 노드 기여'로, §C-1·§C-2 의 `tileIdx` 는 `nodeId` 로 바뀌었다.
> 실제 계약은 언제나 `docs/PROTOCOL.md`(v2)가 정본이다.

사용자 피드백 3건에 대한 설계. ① 너무 어렵다 ② 64칸이 좁고 확장이 없다 ③ 텍스트뿐이고 내가 직접 하는 게 없다.
원칙: 기존 검증된 경제·전투 밸런스를 **곱연산으로 흔들지 않는다**. 새 요소는 가산·선택압·연출로 붙인다.

## A. 난이도 시스템

### A-1. 3단계 프리셋 (건국 화면에서 선택, data/difficulty.json)
| 다이얼 | 이야기(쉬움) | 왕국(보통) | 시련(어려움) |
|---|---|---|---|
| 침공 공격력 배수 | 0.60 | 1.00 | 1.25 |
| 패배 손실 배수 | 0.50 | 1.00 | 1.20 |
| 시작 보너스 | 곡물+100 목재+100 | — | — |
| 이주민 배수 | 1.5 | 1.0 | 0.8 |
| 간접 힌트 폭(성녀 없을 때) | ±1일 | ±2일 | ±3일 |
| 중간충격 | 없음 | 1회 | 1회+강화 |
| 고무줄(패배 시 다음 침공 -10%) | 켬 | 켬 | 끔 |
- 서버는 join 시 `difficulty` 수신, 스냅샷에 저장. 시뮬 체크포인트는 "왕국" 기준 유지 (이야기/시련은 방향성만 확인: 이야기 드래곤 승률 > 왕국 > 시련)

### A-2. 각료 조언 시스템 (어렵다의 진짜 해법 — 문명 고문)
매 틱 서버가 규칙 기반으로 "조언 카드"를 생성 (최대 2건/일, 우선순위순):
- 성벽 없음 & 침공 ≤5일 → 건축가: "성문이 없습니다. [성벽 건설 예약]" (원클릭 실행 버튼 포함)
- 곡물 재고 <3일치 → 농정관: "곳간이 빕니다. [농사 배분 늘리기]"
- D-3 진입 & 국방 배분 <20% → 국방대신: "[긴급 동원령]" (배분 전환 원클릭)
- 골드 여유 & 무기 T0 & 침공 ≤4일 → 공장장: "[무기 제작]"
- 원유 0 & 무기 제작 필요 → 외교관: "[동방 제국과 교역]"
- 확장 가능 → 건축가: "[개척령 반포]"
구현: `advisor.js` 순수 함수 (state → advice[]). NationView에 `advices:[{id,role,text,action:{event,payload},priority}]`. 클라: 조언 카드 = 해당 각료 초상+말풍선+실행 버튼 1개. **실행 버튼은 기존 프로토콜 이벤트를 그대로 쏘는 매크로**라 서버 추가 검증 불필요
- 건국 화면 보조 옵션(기본 켬): "각료 자동 보좌" — 조언을 섭정이 6시간(현실) 방치 시 자동 실행. 끄면 수동

## B. 영토 개척 (64 → 100 → 144)

### B-1. 개척령
- 시작 8×8=64. 개척 1단계 → 10×10=100 (기존 맵 둘레 링 추가), 2단계 → 12×12=144
- 조건·비용 (data/expansion.json):
  | 단계 | 조건 | 비용 | 소요 |
  |---|---|---|---|
  | 1 (100칸) | 감정의 날 이후 + 인구 ≥70 | 목재150 석재80 골드50 + 건설 8pt | 건축 부처가 진행 |
  | 2 (144칸) | 성지 T2 + 인구 ≥140 | 목재300 석재160 골드120 + 건설 16pt | 〃 |
- 의도: 성벽·성지와 **같은 자원을 두고 경합**하는 세 번째 선택지 (§2-3 자원 경합 철학 연장)
- AI 국가도 동일 규칙으로 확장 (세계 뷰에서 커지는 게 보이면 압박감)

### B-2. 새 땅의 보상 — 타일 자질(feature)
확장 링 타일은 즉시 감정 상태로 공개되고, 일부에 자질이 붙는다 (확률 다이얼):
| 자질 | 확률 | 효과 |
|---|---|---|
| 기름진 밭터 | 12% | 이 타일을 밭으로 쓰면 타일 기여 2배 |
| 광맥 노두 | 8% | 채석 지정 시 철광석 +2/일 |
| 우거진 숲 | 12% | 벌목 지정 시 목재 기여 2배 |
| 고대 유적 | 5% (단계당 최소 1 보장) | 탐사 가능(§C-4) |
- **타일 기여 시스템(신규, 가산)**: 지정된 밭/벌목/채석 타일 1칸당 해당 산출 +1% (자질 2배 적용), 상한 +20%. 기존 콥더글러스에 곱하는 게 아니라 마지막에 (1+타일기여) 한 번만 — 상한이 있어 검증 밸런스 안 깨짐. 1막 전용이던 타일 지정이 시즌 내내 의미를 갖게 됨
- 성벽 유지비 증가 없음(단순화). 침공 공격력도 확장과 무관 (확장은 순이익, 대신 비용이 방어와 경합)

## C. 직접 조작 — "왕의 하루"

### C-1. 행동력 (AP)
- 매일 AP 3 회복(이월 없음, 다이얼). HUD에 왕관 아이콘 3개
- 액션(모두 타일/대상 클릭으로 발동, 즉각 연출+효과):
  | 액션 | AP | 효과 |
  |---|---|---|
  | 격려 순행 | 1 | 클릭한 부처 건물/타일의 부처 오늘 산출 +15% (하루 1부처 1회) |
  | 몸소 일하기 | 1 | 지정 타일에서 즉시 자원 획득 (곡물8/목재10/석재5, 도트 튀는 연출) |
  | 유적 탐사 | 1 | 유적 게이지 +1 (3이면 §C-4 이벤트) |
  | 시찰 | 0 | 타일 상세+숨은 자질 힌트 (무료, 쿨 없음) |
- 섭정(오프라인)은 AP를 쓰지 않는다 — **접속한 사람만 얻는 보너스**로 리텐션 원칙(§3-3 "접속한 나라를 이길 수 없다")과 정합. 시뮬 봇은 AP 미사용 기준으로 체크포인트 유지, AP 풀사용 시나리오는 별도 리포트 줄만 추가

### C-2. 수확의 손맛 (스타듀)
- 밭 타일은 3일 주기로 "수확 준비" 반짝임 → 클릭하면 곡물 +6 보너스+팡파레. **안 눌러도 자동 수확에 포함**(누르면 보너스만 추가) — 접속 못 한 죄책감 금지 원칙(§13-6) 준수. AP 소모 없음

### C-3. 침공 지휘 (문명식 전술 선택)
- D-1에 "작전 회의" 모달 자동 제안 (안 열어도 기본 전술로 진행):
  1) 전술 3택: 농성(수성) / 요격(출성) / 화공 — 적 타입별 상성 ±8%p 승률 (해적←화공, 바이킹←농성, 드래곤←요격. 다이얼)
  2) 국방대신 Lv3+ 또는 플레이어가 국방 담당이면 상성 힌트 공개 (정보 비대칭 유지)
  3) 성벽 3구간에 서지 배분 드래그 (약점 구간은 국방부만 표시) — 배분 적중 시 +4%p
- 판정 자체는 기존 로지스틱 그대로, 전술 보정만 가산. `setBattlePlan {tactic, surgeSplit:[3]}`

### C-4. 유적 탐사 이벤트 (선택지 카드)
- 게이지 3 도달 → 카드: "무너진 제단이 있다" → [파헤친다](유물 확률 40%/함정 골드 -30) / [기도한다](사기 +0.05 확정) / [떠난다]
- 카드 풀 6종 (data/ruins.json), 유물 드랍은 기존 등급표 재사용

## D. 프로토콜 추가 (서버 구현 후 PROTOCOL.md에 정본 반영할 것)
- 클라→서버: `expand {}` / `apAction {type:'inspire'|'work'|'explore'|'survey', tileIdx}` / `harvestTile {tileIdx}` / `setBattlePlan {tactic, surgeSplit}` / `adviceAct {adviceId}` / join에 `difficulty` 추가

- 이벤트: `expanded`, `ruinEvent {card}`, 침공 모달 데이터에 전술 결과 명시
