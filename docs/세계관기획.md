## §0. 대원칙 — 스토리는 플레이를 방해하지 않는다

원안 기획의 요구를 게임의 기존 대원칙과 접합한 결과, 아래 여섯 줄이 이 문서 전체를 지배한다.

1. **이 게임은 국가 운영·경영·성장 게임이다.** 스토리는 플레이하면서 자연스럽게 스치는 수준으로만 존재한다. 모든 연출은 이미지+텍스트, 짧게, 건너뛰기 가능.
2. **시간은 아무것도 열지 않는다** (GDD3 §11-1). 스토리 비트도 예외가 아니다 — 모든 연출의 트리거는 플레이어 행동(장 진행·격퇴·건설·거래)이다.
3. **저절로 뜨는 것은 없다.** 초대장·사절단·제안은 알림에 쌓일 뿐, 여는 것은 언제나 플레이어다.
4. **세계는 플레이어 없이도 움직인다.** 3국은 배경 오브젝트가 아니라 자원·재고·가격·정책을 가진 경제 주체다(이미 `ai_nations.json`으로 굴러간다). 이 문서는 그 위에 성장·이벤트·관계 결을 얹는다.
5. **설정만 만드는 것을 금지한다.** 이 문서의 모든 항목은 「플레이어 행동이 어떻게 바뀌는가」로 끝나야 한다. 그렇지 않은 설정은 §9(보류)로 보낸다.
6. **떡밥은 두 번, 이름은 없다.** 세계 균형이 흐트러진다는 낌새(마키나의 잔향)는 정확히 2회의 위화감 대사 + 쿠키 1회로만 존재한다. '마키나'·'혼재' 등 타 작품 고유명은 게임 어디에도 등장하지 않는다 (QA-C 타게임 언급 치환·회귀 테스트와 정합).

## §1. 세계관 정본 — 수에르

### 1-1. 창세 (연대기·성지·유물 플레이버의 원천)
- 우주를 관장하는 신 **아로스**가 외로움 끝에, 자기처럼 "새로운 것에 의미를 부여하는 존재"를 원했다.
- 땅의 신 **테라**가 기반을, 물의 신 **아쿠아**가 흐름을, 불의 신 **이그니스**가 온기를 넣었다.
- 세 원소가 결합하며 파생 원소가 태어났다 — 순환의 **바람**, 충격의 **번개**, 그리고 생명의 **풀**.
- 풀의 원소가 생명을 낳고, 생명이 생각하는 존재로 진화해, 마침내 스스로 세계에 이름을 붙였다: **수에르**.

**설정 보존 노트:** 원안의 "균형이 어긋나는 낌새를 가장 먼저 느끼는 것은 자연·원소에 민감한 이들(수인의 감각, 청명)"이라는 설정은 **설정으로만 보존**한다 — 인게임 위화감 대사는 §0-6의 2회 규칙을 지키기 위해 세라(성녀 결)에게만 준다. 청명 대사에 균형 관련 암시를 추가하지 않는다.

**플레이 접점 (설정 소비처 — 신규 시스템 없음):**
- 성지(발전 건물)의 개축 단계 플레이버 텍스트 = 아로스/테라/아쿠아/이그니스 4신 언급.
- 유물 50종 중 신화 계열 이름·설명에 창세 모티프 사용 (예: "테라의 주춧돌", "이그니스의 불씨" — 기존 유물 리네이밍이 아니라 설명 텍스트 보강).
- 연대기(`L`)의 첫 항목: 수에르 창세 4줄 요약이 "전해 내려오는 이야기"로 깔린다.
- 고대 유적·단서 사슬(trails)의 발견 텍스트가 창세·원소 모티프를 쓴다 (탐험기획과 연결).

### 1-2. 시대 배경
이 게임의 시점은 **균형이 아주 미세하게 어긋나기 시작한 시대**다. 원소들의 간섭과 충돌이 이어져, 짐승들이 제 자리를 벗어나고(늑대 웨이브), 지혜로운 존재가 까닭 없이 싸움을 건다(드래곤). 이유는 게임 안에서 끝내 밝혀지지 않는다 — §7의 위화감 대사 2회가 전부다.

## §2. 3국 정식 개편 — 이름·성향·자원

현재 `data/ai_nations.json`의 임시 3국을 원안 국가로 정식 개편한다.

### 2-1. 매핑표 (정본)

| 항목 | ai1 → **청명(靑冥)** | ai2 → **엘라시아 연합국** | ai3 → **에르니아 왕국** |
|---|---|---|---|
| 기존 임시명 | 동방 제국 | 엘프 연맹 | 서방 왕국 |
| 문화권 | 동양 판타지 (수인의 근원) | 엘프 연합 (숲·하이·다크 3부족) | 유럽 판타지 (인간·엘프·수인 혼재) |
| 위치(도읍 방향) | **극동** — 가장 멂, 운임 최고 | **서편 인접** — 가장 가까움, 운임 최저 | **대륙 중심(동쪽 중거리)** |
| 무역 성향 | 고립주의 — 팔 마음이 있을 때만, 제값에 | 자원 공급국 — 꾸준하고 값이 안정 | 중상주의 큰손 — 뭐든 사고팔되 값을 후려침 |
| persona | `isolationist` (기존 petro 로직 계승) | `supplier` (기존 mercantile 계승) | `hegemon` (유지) |
| 외교 난이도 | **hard** (유지) | **easy** (normal→easy 변경) | **normal** (easy→normal 변경) |
| 주 수출 | **강재·철광석** — 소량·고가 | **목재·원유·석재** — 대량·안정 | **곡물·자본** — 대량, 덤핑 |
| 주 수입 | 거의 없음 (곡물 소량) | 강재·가공품 | 원유·연료·희귀재 |
| 시작 골드 | 180 (유지) | 120 (유지) | **260 (최다 — 유지)** |
| 관계 결 | 신의(信義) — 느리게 쌓이고 배신에 무너짐 | 세 부족 — 쉽게 열리나 출렁임 | 재회 — 위신을 쌓으면 대등해짐 |
| 한 줄 | 얻기 어려운 신의의 벗 | 가까운 이웃, 협력과 경쟁 | 갈라선 본국, 재회의 상대 |

### 2-2. 자원 재배치 결정 ★ (밸런스 게이트 필수)

원안 충실 매핑을 위해 **유전(oilfield) 태그와 원유 수출을 청명→엘라시아로 이전**한다. 근거:

- 원안: 엘라시아가 "땅속의 기름"을 가진 연료 공급국, 청명은 "소량의 희귀재"만 제값에 파는 고립국.
- 플레이 효과: 원유(화포 원료)의 공급자가 hard 국가에서 easy 국가로 바뀌어, **화포 무역 사슬이 "초반 이웃과의 꾸준한 거래"로** 자연스러워진다 (QA-F3 무역 동기 강화와 방향 일치).
- 청명의 독점재는 **강재(steel)** 로 정한다. 자국 제련보다 싸고 질 좋은 강재를 청명이 쥔다 — "후반 특정 산업(화포·노포·상급 개축)을 키우려면 반드시 이 문을 두드리게 된다"는 원안 문장이 그대로 플레이가 된다. 단 §3-2의 신의 임계를 넘어야 대량 거래가 열린다.

| 다이얼 | 변경 | 값(제안) |
|---|---|---|
| 청명 tags | `oilfield` 제거 | `["ironvein", "barren"]` |
| 청명 preferredExports | oil 제거 | `["steel", "ironOre"]` |
| 청명 startingResources.oil / steel | 20→0 / 10→40 | 강재 비축국 |
| 엘라시아 tags | `oilfield` 추가 | `["greatwood", "oilfield", "holy"]` |
| 엘라시아 preferredExports | oil 추가 | `["wood", "oil", "stone"]` |
| 엘라시아 criticalImports | oil·fuel 제거, steel 추가 | `["steel"]` |
| 엘라시아 startingResources.oil | 0→25 | — |
| 에르니아 criticalImports | `["oil", "fuel", "steel"]` | 희귀재 수요자 = 플레이어의 중계무역 기회 |

**게이트:** 이 변경은 무역 시세·화포 접근성에 직접 영향 → `npm run simulate` 4/4 (특히 웨이브 5 생존율 60~80% 유지) 통과 전 머지 금지. 실패 시 롤백 1순위는 청명 steel 비축량, 2순위는 엘라시아 oil 산출 계수.

**근사 처리 2건 (원안 ↔ 게임 자원 체계 7종의 간극):**
- **에르니아의 수출 "가공품·공산품 전반"** — 게임에 공산품 자원이 없다. 곡물 대량 수출 + 최다 골드(자본) + 덤핑(dumpingChance 이관)으로 "남는 물자를 싸게 풀어 시장을 장악하는 큰손"을 근사한다. fuel 재수출(사들인 원유를 정제해 되파는 흐름)은 hegemon 정책 다이얼로 표현 가능하면 반영.
- **엘라시아의 "희귀 약초"** — 현재 게임에 약초 자원·아이템이 없다 (`ai_nations.json`의 concept 문구뿐). concept 문구는 유지하고, **QA-F2(바이옴 10+)에서 약초·포션류 아이템이 생기면 엘라시아 독점 공급으로 연결**한다. W4 체크리스트에 조건부 항목으로 등재.

### 2-3. 도읍 배치·운임 (연출+다이얼)
- 월드 프리셋 도읍 방향: 엘라시아 = 플레이어 도읍에서 가장 가까운 모서리, 에르니아 = 중거리, 청명 = 최원거리.
- 무역 실효가의 운임 항이 거리 비례라면 그대로 살리고, 아니면 국가별 운임 계수 다이얼(엘라시아 0.9× / 에르니아 1.0× / 청명 1.2×)로 근사한다. → "가까운 이웃과 먼 전통국"이 시세로 체감된다.

## §3. 국가별 관계 결 — 단순 호감도의 폐지

세 나라 모두 같은 관계 게이지를 쓰되, **오르내리는 규칙과 임계 보상이 국가마다 다르다.** 신규 시스템이 아니라 기존 신뢰/관세/제안 체계 위의 국가별 다이얼이다.

### 3-1. 에르니아 — 「재회(再會)」
- **오르는 법:** 거래량 + **위신 이벤트**(티어 승격, 웨이브 격퇴, 유물 획득)에 자동 반응. 에르니아는 플레이어의 '성장'을 지켜보는 나라다.
- **내리는 법:** 거의 없음. 다만 관세 전쟁·계약 파기 시 "실망" — 회복은 빠르다.
- **호칭 단계 (무역·사절 대사에 반영):** ① "서쪽으로 떠난 옛 영웅들" (티어≤3) → ② "신흥국 {정착지명}" (티어 4~5) → ③ "{정착지명}의 국왕" (엔딩 후).
- **임계 보상:** 게이지 임계 + §8 엔딩 조건 충족 → **초대장** (엔딩 게이트).
- **거래 특성:** 뭐든 사주는 큰손이되 매입가를 후려친다(기존 hegemon 로직 + dumpingChance를 에르니아로 이관). 급할 때 기댈 수 있지만 계속 기대면 손해 — 종속의 압력을 시세로 표현.

### 3-2. 청명 — 「신의(信義)」
- **오르는 법:** 오직 **계약 이행**. 성사된 거래 1건당 소폭, 연속 이행 보너스. 위신·선물로는 오르지 않는다.
- **내리는 법:** 제안 거절 연발·계약 만료 방치 시 소폭, **바가지 역제안 시 대폭.** 한번 크게 잃으면 회복이 매우 느리다.
- **임계 보상:** 신의 임계를 넘으면 **독점 강재 제안**(대량·특별가, 다른 곳에 없는 물량)이 열린다. 후반 군비·개축의 지름길.
- **거래 특성:** 제안 빈도 최저, 물량 소량, 가격 협상 불가(제값). 첫 거래 자체가 낮은 신의 임계를 요구한다 — "문을 두드리는" 경험.

### 3-3. 엘라시아 — 「세 부족의 목소리」
- **오르는 법:** 쉽다. 초반 거래 몇 건이면 열린다 — 의도된 첫 무역 상대.
- **출렁임:** 내부에 숲/하이/다크 세 부족 파벌이 있어, **부족 회의 이벤트**(§4)에 따라 수출 품목·가격·태도가 주기적으로 변한다. 관계가 깎이는 게 아니라 "이번 분기 목소리"가 바뀌는 것.
- **임계 보상:** 원자재 정기 계약(매 틱 자동 소량 공급, 시세 무관 고정가) — 안정의 나라다운 보상.
- **거래 특성:** 제안 빈도 최고, 원자재 위주, 가격 안정. 단 부족 회의 결렬 중엔 일시 중단될 수 있다.

**구현 노트:** 관계치는 국가별 스칼라 1개 + 다이얼(`gainPerTrade`, `gainPerPrestige`, `lossOnRefuse`, `thresholds[]`)로 충분하다. UI는 외교관 화면의 국가 카드에 게이지+현재 호칭 한 줄.

### 3-4. 역할별 접근 결 — 같은 나라, 다른 경험
원안의 "누가 접근하느냐에 따라 완전히 다른 경험"을 기존 **역할 정보 비대칭**의 확장으로 구현한다. 신규 화면 없이, 역할에 따라 국가 카드에서 보이는 것·할 수 있는 것이 달라진다.

| 역할 | 3국에서 그 역할에게만 열리는 것 |
|---|---|
| 외교관 | 관세 협상·조약 수락 권한, 타국 실시간 시세(기존), 부족 회의·왕위 계승의 사전 첩보 |
| 국방부 | 국가별 군사 결 정보 — 청명과 신의 임계 시 「무예 교류」(민병 전투력 소폭 버프 계약) |
| 성녀 | 국가 이벤트(§4)의 발생 예고가 예언 채널에 포함 — "엘라시아의 숲이 탈 것 같습니다" |
| 농정관·공장장 | 자기 품목의 국가별 매입가 비교(어디에 팔면 이득인지), 청명 강재 특가의 실효 이득 계산 표시 |
| 건축가 | 엘라시아 정기 계약(원자재)의 공사 계획 연동 표시 |

**규칙:** 어떤 역할도 다른 역할의 권한을 대신할 수 없다(수락 버튼은 외교관 또는 위임 봇). 정보만 다르게 보인다 — 협동의 대화 소재가 되는 것이 목적이다.

## §4. 살아있는 세계 — 국가 이벤트와 연쇄

## §5. 국가의 얼굴 — 사절 NPC

국가별 고정 인물을 두고, 무역 제안·이벤트·사절단 대사의 화자로 쓴다. 잼 범위에서는 **이름+한 줄 말투 규칙이 템플릿(`templates.ko.json`)에 반영**되는 수준이다 (초상은 에셋 명세에 추가, §10).

| 국가 | 인물 | 역 | 말투 결 | 등장처 |
|---|---|---|---|---|
| 에르니아 | **국왕 아르텐** | 옛 군주, 재회의 상대 | 위엄+회한, 플레이어를 "그대"라 부름 | 도입·초대장·엔딩 |
| 에르니아 | **사절 로웬** | 상무 사절 | 정중하나 계산적 | 무역 제안·왕위 계승 이벤트 |
| 청명 | **장로 담선** | 문파 연합의 장로 | 짧고 단정한 하오체 | 무역 제안·신의 임계·새 문파 이벤트 |
| 엘라시아 | **대변인 리엔** | 세 부족 연합 대변인 | 부드럽지만 "부족들의 뜻이…"로 말끝이 자주 바뀜 | 무역 제안·부족 회의·숲 화재 이벤트 |
| 플레이어측 | **순례자 세라** | 첫 이민자 → 성녀 후보 | 맑고 조심스러움, 위화감을 먼저 느낌 | §6·§7 스토리 전반 |

**호칭 규칙 (QA-A '그대' 제거와의 정합):** UI·시스템 텍스트에서 2인칭 호칭 금지는 유지. 단 **연출 대사 안에서 인물이 플레이어를 부르는 호칭**(아르텐의 "그대", 세라의 "{군주명}님")은 캐릭터의 목소리이므로 허용한다.

**세라 화자 규칙 ★:** 원안의 '성녀' 대사는 관제 선포(6장) 이전에도 나온다. 해결 — 세라는 4장 「첫 이웃」의 첫 이민자로 고정 등장하는 **인물**이며, 관제 선포에서 성녀 자리의 기본 NPC가 된다. 플레이어(멀티 포함)가 성녀 역할을 직접 맡으면 세라는 성소의 보조 인물로 남고, 이후 성녀 예언 대사는 화자 표기를 "성녀의 직감"(시스템 결) 으로 바꿔 내보낸다. 스토리 대사가 역할 선택과 충돌하지 않게 하는 유일한 규칙이다.

## §7. 대사 정본 (스크립트)

원안 대사를 게임 컨벤션(호칭 규칙 §5, 정착지명 변수 `{name}`, 군주명 `{lord}`)에 맞춰 확정한다. **아래가 인게임 수록 정본이다.** 연출은 전부 스킵 가능.

**압축 편집 원칙 (§0-1 근거):** 원안 중 플레이어의 확인형 응답 일부("…그저 굶주렸던 것 아닌가?", "한숨 돌렸군" 등)는 연출 길이를 줄이기 위해 **자막(내레이션)으로 흡수**했다 — 멀티에서 군주가 여럿일 수 있어 1인칭 확정 대사를 줄이는 목적도 있다. 정보가 있는 문답(아래 복원분)은 원안대로 살린다.

  > **세라:** "…다들, 괜찮으신가요? 피해가 커요."
  > **세라:** "그런데… 이상하네요. 늑대들이 이렇게 무리 지어 사람을 덮치다니…"
  > **자막:** *그저 굶주렸던 것이라면, 좋겠지만.*

### 7-4. 3막 — 국가 발전
- **8장 첫 상단 (사절단 겸):**
  > **외교관 결 대사:** "기쁜 소식입니다. 마침내 첫 상단이 우리를 찾아왔습니다 — 바깥 세상이, 우리의 존재를 알기 시작한 모양입니다."
- **드래곤 최초 예고:**
  > **성녀의 직감:** "지금까지와는 다릅니다. 무언가… 거대한 것이, 다가오고 있어요."
- **드래곤 최초 격퇴 (턴 포인트 · 떡밥 2회차·최종):**
  > **세라:** "해냈어요…! 우리가, 드래곤을 격퇴했어요!"
  > **자막:** *저것마저 막아냈다면, 이제 우리는 어떤 나라와도 대등하다 할 수 있으리라.*
  > **세라:** "…그런데 이상합니다. 드래곤은 본디 지혜로운 존재라, 함부로 싸움을 걸지 않는데…"
  > *(이후 이 위화감은 게임에서 다시 언급되지 않는다)*
- **초대장 (알림 카드):**
  > "에르니아 왕국에서 초대장이 왔습니다. 국왕께서, {lord}님을 직접 뵙고 싶다 하십니다." — [에르니아로 간다] / [아직은 때가 아니다]

### 7-5. 엔딩 (이미지+텍스트)
> *오랜만에 마주 앉은 두 사람은 차를 나누었고, 왕은 그간 그대가 걸어온 길을 들었다.*
> **아르텐:** "그대의 이야기는 언제 들어도 흥미롭군. 그래, 앞으로의 계획은 어떻게 되는가?"
> **{lord}:** "우리의 나라를 계속 키워갈 생각입니다. 미지의 땅에서의 시작은… 생각보다 훨씬 큰 걸음이 되었습니다."
> *왕은 찻잔을 내려놓더니, 살짝 웃었다.*
> **아르텐:** "그래, 그대… 아니, **{name}의 국왕**이여. 앞으로도 저희와 함께 걸어주시겠습니까?"
> *왕이 손을 내밀었고, 그대는 미소와 함께 그 손을 잡았다.*
> **{lord}:** "…영광입니다, 국왕이여."
> *— 언젠가 마주 앉을 날을 기대한다던 그 말이, 마침내 이루어지는 순간이었다.*

### 7-6. 크레딧 + 쿠키
크레딧(팀·AI 활용 고지 포함) 롤 후, 쿠키 1장:

> *잔치의 불빛이 성벽 너머로 잦아들 무렵, 세라는 홀로 창가에 서 있었다.*
> **세라:** "…우리는 결국, 해냈네요."
> **{lord}:** "그래. 여기까지 왔군."
> *바람이 한 줄기 불어와 그녀의 머리카락을 스쳤다. 아주 잠깐, 그 어깨가 굳는 것을 그대는 보았다.*
> **세라:** "그런데 왜일까요. 이겨냈는데도… 자꾸만 저 서쪽 하늘이 마음에 걸려요."
> *이윽고 그녀는 천천히 고개를 젓고, 돌아서며 언제나처럼 옅게 웃었다.*
> **세라:** "…아니요. 오늘만큼은 아무것도 생각하지 않을래요. 우리의 첫 매듭이잖아요."
> *창밖으로, 바람이 다시 서쪽에서 불어오고 있었다.*

**규칙:** 쿠키는 타 작품명을 일절 쓰지 않는다. "서쪽 하늘"·"바람"의 이미지만 남긴다. (사용자 확정: 쿠키 수록)

## §8. 매듭형 엔딩 — 끝이 아니라 매듭

게임은 엔드리스다. 엔딩은 게임을 끝내지 않고 **첫 매듭**을 짓는다 (사용자 확정).

- **조건 (3중, 전부 다이얼):** ① 드래곤 최초 격퇴 ② 에르니아 재회 게이지 임계 ③ 티어 5(도시) 도달. 충족 시 다음 아침 알림에 초대장 — 저절로 열리지 않는다.
- **보류 선택:** [아직은 때가 아니다]를 고르면 초대장은 알림에 남는다. 언제든 다시 연다.
- **연출 중 게임:** 엔딩 연출·크레딧 동안 서버 시계는 그대로 흐른다(멀티 정합). 연출은 클라 오버레이일 뿐이다. 웨이브 당일에는 초대장을 열 수 없다("지금은 성을 비울 수 없다" 한 줄).
- **엔딩 후:**
  - 연대기에 「첫 매듭」 대형 항목 기록.
  - 에르니아 호칭 3단계("{name}의 국왕") + 재회 보너스(관세 최저·제안 빈도↑) 영구 적용 — 엔딩의 플레이 보상.
  - **기념비 개축 해금** 또는 전용 장식 1종("재회의 다탁") — 눈에 보이는 기념물.
  - 엔딩 재감상은 연대기에서. 초대 연출은 1회만.
- **멀티:** 초대장을 여는 것은 아무나 가능하되 확인 창에 "모두와 함께 봅니다" 명시. 전원에게 동시 재생.

## §9. 잼 범위 밖 — 정직한 보류 목록

원안의 다음 요구는 **잼 버전에서 구현하지 않고**, 이 문서를 정본 삼아 잼 이후 확장한다. 잼 범위에서 그 "느낌"을 무엇으로 대신하는지를 함께 적는다.

| 원안 요구 | 잼에서의 대체물 | 잼 이후 방향 |
|---|---|---|
| NPC 국가 = 플레이어와 동일 규칙의 AI 플레이어 (건설·도시 확장 실행) | 자원·재고·가격·정책 시뮬(현행) + 국가 성장 다이얼(틱당 인구·산출 성장률, 국가별 성장 결: 에르니아=경제·청명=문화·엘라시아=자원) | 국가별 미니 정착지 시뮬, 월드에 도시 확장 시각화 |
| NPC가 플레이어 행동을 기억, 몇 년 뒤 재등장 | 관계 게이지 + 호칭 단계가 기억을 대신 표현 | 인물 단위 기억·재배치 시스템 |
| 국가별 다인 NPC 구성 (왕·재상·귀족·기사·학자·길드장·장인 등) | 국가당 사절급 1~2인(§5)만 — 얼굴 있는 최소 구성 | 국가별 궁정 인물망, 인물별 퀘스트 |
| 역할 간 플레이어 경제 (장인→상인→외교관 사슬) | 기존 협동(공유 창고·역할 정보 비대칭)으로 충분 | 개인 지갑·플레이어간 거래 |
| 국가 레벨·기술·문화 수준 지표 | 성장 다이얼로 내부 표현만 (UI 미노출) | 외교 화면에 국가 성장 지표 노출 |
| 영토 분쟁·전쟁·동맹 등 국가간 군사 외교 | 이벤트 텍스트로만 언급 | 국가간 관계 그래프·전쟁 시스템 |

**보류의 근거:** 대원칙 5 — 플레이로 이어지지 않는 깊이는 지금 만들지 않는다. 잼 심사에서 보이는 것은 "세 나라가 다르게 굴고, 세계가 나 없이도 변한다"는 체감이며, 위 대체물로 충분히 달성된다.

## §10. 구현 계획 — opus 배치 W1~W4

QA 큐(E 진행 중 → F1~F4)와 충돌하지 않도록, **W1은 즉시 가능**하고 W2~W4는 QA-F 배치 사이에 끼워 넣는다. 각 배치는 「구현 → npm test → simulate(해당 시) → 커밋 → AI활용.md 갱신」의 기존 리듬을 따른다.

### W1 — 3국 정식 개편 (데이터 중심 · QA-E와 병행 가능)
- `ai_nations.json`: 이름·concept·persona·난이도·태그·자원 재배치 (§2 표 그대로). 도읍 방향·운임 계수.
- `templates.ko.json`: 국가명 치환 + 사절 인물명(아르텐·로웬·담선·리엔) 화자 반영, 국가별 말투 결 1~2 변형.
- 유물·연대기 플레이버에 3국 정식명 반영 (artifacts.json의 기존 언급 정합 확인).
- **게이트:** `npm test` 전량 + `npm run simulate` 4/4 (자원 재배치 영향). 하니스 무역 항목.

### W2 — 스토리 연출 계층 + 1·2막 (F1 전후 권장)
- 연출 시스템: 기존 감정의 날 컷신 오버레이를 일반화한 `storyBeat` (이미지 슬롯+텍스트 시퀀스+스킵, 서버가 재생 상태 권위·1회 보장·방송). `data/story.json` 신설 — 대사 전문은 §7이 정본.
- 도입 연출(7-1)·1막 대사(7-2, 세라 고정 이민자 포함)·2막 대사(7-3, 웨이브 분기).
- 세라 화자 규칙(§5) — 성녀 역할 점유 상태에 따른 화자 전환.
- **게이트:** npm test + 하니스에 "1장→7장 마커 주행 중 연출 1회씩·스킵 동작" 항목 추가.

### W3 — 3막 + 매듭형 엔딩 + 쿠키 (F2 드래곤 구현 뒤 필수)
- 드래곤 예고·격퇴 턴 포인트(7-4), 초대장 알림(조건 3중 다이얼), 엔딩·크레딧·쿠키(7-5·7-6), 엔딩 후 보상(§8).
- F2의 "용 1마리"와 같은 배치로 묶는 것을 권장 — 드래곤 전투와 그 내러티브 보상이 한 호흡.
- **게이트:** npm test + 시뮬 봇 85일 주행에서 엔딩 조건 도달 여부 리포트(도달 중앙값 기록 — 밸런싱 자료).

### W4 — 관계 결 + 국가 이벤트 연쇄 (F3 무역 동기와 같은 배치 권장)
- 관계 게이지+국가별 다이얼(§3), 외교 화면 국가 카드(게이지+호칭), 청명 독점 강재·엘라시아 정기 계약·에르니아 위신 연동.
- `events.json` nations 풀 8종(§4, 도움 요청 2종 포함) + 연쇄 처리 + 역할별 접근 결(§3-4).
- 조건부: F2에서 약초·포션류 아이템이 생겼으면 엘라시아 독점 공급 연결(§2-2 근사 노트).
- **게이트:** npm test + simulate 4/4 (이벤트가 시세를 흔드므로) + 하니스 외교 항목.
