# 신전 내부 에셋 목록 — 10종 기준

다음 에셋은 신전 내부 구현 세션을 위한 제작 목록이다. 현재 야외 신전의 진행(`수수께끼 → 수호자 → 안치소`)은 유지하고, 내부 공간은 그 세 단계를 시각적으로 연결한다.

## 공통 재사용 에셋

아래는 신전마다 새로 만들지 않는다.

- 내부 바닥 타일: 16×16, 반복 가능한 석재 바닥 4종
- 내부 벽·기둥·균열: 16×16 또는 32×32, 공통 베이스
- 문: 닫힘 / 열림 2상태
- 안치대: 비어 있음 / 빛남 / 획득 후 3상태
- 룬석·레버: 비활성 / 활성 2상태
- 공통 파티클: 금빛 획득, 푸른 룬, 먼지, 빛기둥
- 수호자 애니메이션 규격: 대기 4프레임 · 이동 4프레임 · 공격 4프레임 · 피격 2프레임 · 사망 4프레임

권장 수호자 기본 프레임은 32×32px이다. 기존 필드 몬스터보다 한 단계 큰 실루엣으로 만든다.

## 신전별 신규 에셋

| 신전 | 환경·입구 키워드 | 수호자 | 전용 유물 테마 | 팔레트 |
|---|---|---|---|---|
| 얼어붙은 신전 | 성에 낀 돌문, 얼음 기둥, 눈 제단 | 다이어울프 | 얼어붙은 왕의 홀 | 청백·은색 |
| 덩굴에 삼켜진 신전 | 거목 뿌리, 덩굴 아치, 물 고임 | 정글 표범 | 아쿠아의 성배 | 녹색·청록 |
| 뿌리의 신전 | 굵은 뿌리, 이끼 낀 제단, 나뭇잎 천장 | 곰 | 세계수의 씨앗 | 짙은 녹색·갈색 |
| 깊은 돌의 신전 | 암벽 문, 광맥, 갈라진 비석 | 도적 정찰병 | 테라의 주춧돌 | 회색·황동 |
| 풍요의 신전 | 이삭 무늬, 곡물 제단, 흙 항아리 | 멧돼지 | 풍요의 뿔 | 금빛·황토 |
| 모래바람 신전 | 모래에 묻힌 석주, 바람 문양, 매달린 천 | 모래도마뱀 | 폭풍의 망토 | 모래색·청회 |
| 가라앉은 신전 | 검은 물, 젖은 계단, 물결 룬 | 늪의 잠복자 | 아로스의 눈 | 남청·청록 |
| 잿불 신전 | 균열 난 용암석, 재, 불씨 화로 | 재 사냥개 | 이그니스의 왕관 | 주홍·검정 |
| 포자의 신전 | 거대 버섯, 포자 안개, 균사 제단 | 포자 보행자 | 죽음의 낫 | 보라·연두 |
| 황혼의 신전 | 길어진 그림자, 초승달 룬, 어스름 창 | 재 웜 | 아로스의 성표 | 남보라·금색 |

각 신전마다 새로 필요한 항목은 아래 다섯 가지다.

- 입구 외관 1종: 48×64 또는 64×64
- 내부 장식 세트 3~5종: 기둥, 제단 주변물, 벽 장식, 바닥 장식
- 안치대 오버레이 1종: 전용 유물의 색·문양 반영
- 수호자 스프라이트 세트 1종: 위 공통 애니메이션 규격 적용
- 전용 룬/문양 1종: 문, 수수께끼 선택지, 미니맵 마커에 재사용

## 제작 우선순위

1. 신전 입구 10종과 전용 룬 10종
2. 수호자 10종의 대기·이동·공격·사망 스프라이트
3. 안치대 오버레이 10종
4. 공통 내부 타일·문·레버·파티클
5. 신전별 내부 장식 세트
