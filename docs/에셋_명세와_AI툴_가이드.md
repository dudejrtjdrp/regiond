### 반드시 지켜야 하는 3가지 규약

**① 앵커 = 하단 중앙 (bottom-center)**
`world.json` → `render.structureSprite`: `scale 1.18 / pad 0.7 / baseDrop 0.55 / shiftX 0.1`
스프라이트는 풋프린트 사각형보다 1.18배 크게 그려지되 **밑변과 가로 중앙이 붙박이**로 고정된다. 그림과 클릭 판정이 `GM.world.structureRect` 하나를 공유하므로 앵커가 어긋나면 클릭이 안 먹는다.

**② 밤에도 minLuma 56 이상**
`world.json` `light.phases` — 밤은 tint `#16214a`, alpha **0.46**(46% 어둡게). 스모크 테스트가 화면 평균 밝기 하한 56을 실측 검증한다. **에셋 색을 너무 어둡게 잡으면 테스트가 깨진다.** 밝은 중간톤 + 별도 emissive(창문/불빛) 레이어가 정답.

**③ 팔레트 정본 (`icons.js` C 객체)**
```
ink #3b2318    dark #2b1a12   wood #5d4037   woodL #8d6e63
paper #f4e4bc  paperL #fdf3d8
gold #e8a33d   goldL #f6cf7a  goldD #a8701f
green #6a994e  greenL #8dbb6d greenD #3f6130
red #bc4749    redL #d9706f   redD #7d2a2c
blue #4a6fa5   blueL #7b9bc9  violet #8367a8  violetL #b39ad6
grey #9aa0a8   greyL #c4cad2  greyD #5e646c
skin #e6b892   skinD #c08f64  white #fdf8ec   black #1a1008
```
AI에 생성시킬 때 **이 24색을 프롬프트에 hex로 박아 넣는 것**이 톤 통일의 핵심이다.

### 방향 · 프레임 (코드에 이미 있는 것)

| 항목 | 현재 상태 |
|---|---|
| 방향 | `dir` 0=아래 1=왼 2=오른 3=위 **인덱스는 계산되나** 실제 그림은 `if (dir !== 3)` 하나뿐 = 사실상 **정면/후면 2종**. 좌우 미러링 미구현 |
| 걷기 | **2프레임** 토글 (0.17초 주기, 약 5.9fps) |
| 스윙 | **3자세** (대기 / 치켜듦 / 내려침) — WINDUP 0.10s → 임팩트 → FOLLOW 0.13s |
| 피격 | 프레임 없음, 붉은 틴트 오버레이로 대체 |
| 사망 | 프레임 없음, 파편 12개 + 링 + hitStop 90ms로 대체 |
| 건물 티어 | 정적 4단 (`clamp(tier,1,4)`) — 5·6단 데이터가 있어도 그림은 4단에서 멈춤 |
| 밭 성장 | 4단계 (sown/sprout/grow/ripe) |

> **핵심 인사이트:** 코드가 이미 4방향 인덱스를 계산하고 있다. **4방향 스프라이트를 그려 넣으면 코드 수정 거의 없이 바로 개선된다.**

| **캐릭터 스프라이트시트 + 걷기/공격 애니** | **PixelLab** | Sprite-AI | 스켈레톤 애니 + 텍스트→애니메이션이 유일하게 제대로 됨 |
| **4/8방향 회전 스프라이트** | **PixelLab** | (대안 사실상 없음) | 자동 방향 회전 생성이 PixelLab 독점 기능 |

| **무료로 때우기** | **AutoSprite** (월 2회 무료) | DeepAI, OpenArt | 품질은 기대 낮게 |

## 3-2. 툴별 상세

### 🥇 PixelLab — 이 프로젝트의 주력이 되어야 할 툴
- **가장 잘하는 것:** 스켈레톤 기반 애니메이션 · **4/8방향 자동 회전** · 타일셋 · true 인페인팅 · 캐릭터 크리에이터(걷기/달리기/공격)
- 아이소메트릭 맵도 지원하지만 이 프로젝트는 탑다운이라 무관
- Aseprite 플러그인 + **API 제공** → 배치 생성 스크립트 가능
- 해상도 상한 320~400px (우리 최대 캔버스 128×176이므로 충분)
- 가격: **$12~50/월** (2,000~10,000장), 무료 티어 없음
- 약점: 복잡한 애니메이션에서 프레임 일관성이 흔들림
- **이 프로젝트 적용:** 아바타 4방향 × 걷기2 × 스윙3, 주민 10직업, 야생 12종 + 적 6종 모션, 지형 7종 타일셋 — **필요 장수의 60% 이상을 여기서 뽑는 게 맞다**

### 🥈 Retro Diffusion — "진짜 도트" 품질 담당
- **가장 잘하는 것:** 픽셀 그리드가 실제로 맞는 출력. AI 티가 가장 덜 남
- **Aseprite 확장**으로 에디터 안에서 생성 → 즉시 수동 수정 (도트 작업 파이프라인에 그대로 녹음)
- 가격: **웹 ~$0.01/장** (50 무료 크레딧) 또는 **Aseprite 확장 $65 일회성**. LITE 버전 별도
- ⚠️ **함정:** *웹사이트와 Aseprite 확장은 같은 도구가 아니다.* 확장은 더 작은 모델이라 애니메이션 미지원, 웹은 FLUX 등 상위 모델. 애니메이션이 필요하면 웹/API를 써야 한다
- **이 프로젝트 적용:** 건물 36종 × 4티어(정적이라 애니 불필요, 품질이 최우선) · 자원 노드 · 트레일 흔적 · 아이콘

### 🥉 Scenario — 톤 통일 담당
- **가장 잘하는 것:** 내 레퍼런스로 **커스텀 LoRA 학습** → 550개 모델 · 노드 기반 워크플로 · 상업 라이선스 명확
- 가격: **~$15~20/월**, 커스텀 학습 $45/월~
- 약점: **애니메이션 없음, 스프라이트시트 파이프라인 없음** — 단품 이미지 생성기
- **이 프로젝트 적용:** 위 24색 팔레트로 아이콘 20~30장을 먼저 손으로/RD로 만들어 LoRA 학습 → **유물 50 + UI 73 + 스킬 40 = 163장을 한 톤으로** 뽑는 용도. 여기가 가장 큰 가성비 포인트

### Sprite-AI — 저예산 대안
- 게임용 사이즈(16×16~128×128)로 바로 생성 · 브라우저 에디터 · **8~24프레임 애니메이터**
- 익스포트: PNG / 스프라이트시트 / GIF / 아틀라스 / SVG
- 가격: **$8/월** 또는 $10~ 크레딧팩, 무료 15장 체험
- PixelLab 예산이 안 되면 여기

### Ludo.ai — 올인원
- 30+ 아트스타일 · 모션 프리셋 애니 · **Unity/Godot/GameMaker 익스포트** · 타일·UI·3D·오디오까지
- 전용 **타일셋 제너레이터** 별도 제공
- 가격: $20/월, Pro $50/월 무제한

### Layer.ai — 팀용
- **팀 시트 무제한** · Photoshop/Blender/Unity 연동 · 엔진별 스프라이트시트 툴
- 가격: 사용량 기반 (~$0.06/Creative Unit, 실사용 월 ~$60)
- 팀(김대윤·강동현)이 같이 붙어야 하면 고려

### AutoSprite — 무료 시작점
- 애니메이션 중심 · 엔진 익스포트 · **오픈소스 Unity 확장** · 배치 파이프라인
- 가격: **무료 2회/월** → $12/월 Starter → $29/월 Pro

### Nano Banana Pro (Gemini) / GPT Image — 큰 그림 담당
- **가장 잘하는 것:** 유적 카드 12종 · 컷신 480×270 · 각료 초상 · 콘셉트 시안 — **구도와 서사가 있는 큰 이미지**
- 픽셀 그리드는 못 맞춘다 → **다운스케일 + 팔레트 양자화 후처리 필수**
- ⚠️ 실전 교훈 (검증된 워크플로):
  - **투명 배경 생성 불가.** 순수 녹색 `#00FF00` 배경 + 흰 아웃라인으로 뽑고 **HSV 크로마키**(hue ±22°, sat ≥0.3)로 제거
  - **균등 그리드 슬라이싱 실패.** 스프라이트 폭이 제각각이라 → 내용 인식 슬라이싱(비투명 영역 검출 → 자동 트림 → 리사이즈)
  - 안티에일리어싱이 가장자리에 배경색을 구워 넣음 → 후처리로 완전 제거 불가
  - 여러 시트를 따로 생성하면 **비율이 드리프트** → 한 번에 뽑아야 함
  - **런타임 틴트보다 색 변형본을 미리 생성**하는 게 작은 사이즈에서 훨씬 낫다 → 우리 적 변형 5종(굶주린/무리 지은/…)에 그대로 적용

### 쓰지 말 것 (이 프로젝트 기준)
- **Adobe Firefly** — 정확한 픽셀 치수 지정 불가, 2000×2000로 나옴
- **OpenArt / DeepAI** — 스프라이트시트 익스포트 없음, 픽셀 사이징 없음. 콘셉트 시안용으로만
- **Meshy / Tripo / Rodin / Luma** — 전부 3D. 우리와 무관

# PART 4 — 실전 계획

## 4-1. 우선순위

**P0 — 지금 화면이 깨져 보이는 것 (에셋 없이도 고칠 수 있음)**
1. 아이콘 4종 추가: `meat` `hide` `wool` `boot` — 현재 고기·가죽·털이 **전부 돌멩이**로 표시됨
2. 건물 STYLE 3종 추가: `appraisal_post` `claim_flag` `ranch` — 기본 gable로 표시됨
3. `buildings.json` production.order에 `ranch` 추가 (데이터 버그)
4. 적·야생 **공격 모션** — 서버는 1.2초마다 때리는데 화면에 표시가 없음
5. 아바타 **다운 자세** — 10초간 정지 프레임

**P1 — 픽셀아트 전환의 핵심 (체감 변화가 가장 큼)**
6. 지형 7종 + autotile 전이 (지금 격자가 그대로 보임)
7. 건물 36종 × 4티어
8. 아바타 레이어 시스템 — **팔레트 스왑 구조 반드시 유지**
9. 야생 12 + 적 6 이동·피격·사망

**P2 — 완성도**
10. 유물 50 아이콘 · 유적 카드 12
11. 이펙트 시트 · 영토 말뚝+밧줄 · 운반물 들짐
12. 밤 emissive 레이어 (창문·모닥불·가로등)

## 4-2. 게임잼 마감이 촉박할 때의 최소 세트

전량 1,500장은 잼 일정에 불가능하다. **"픽셀아트로 갈아탄 것처럼 보이는" 최소 조합은 약 180장:**

| 항목 | 장수 | 툴 |
|---|---|---|
| 지형 7종 × 4변주 | 28 | PixelLab 타일셋 |
| 건물 상위 12종 × 2티어 (자주 보이는 것만) | 24 | Retro Diffusion |
| 본부 6단 | 6 | Retro Diffusion |
| 아바타 베이스 4방향 × 5프레임 | 20 | PixelLab |
| 주민 3직업(농부·나무꾼·건설) 4방향 × 2 | 24 | PixelLab |
| 야생 6종 + 적 6종 이동2 | 24 | PixelLab |
| 자원 아이콘 14 | 14 | Scenario |
| UI 아이콘 상위 30 | 30 | Scenario |
| 이펙트 슬래시·링·먼지 | 12 | Retro Diffusion |
| **합계** | **182** | |

나머지는 **현재 절차 생성을 fallback으로 남겨두면 된다** — 이게 이 프로젝트의 가장 큰 자산이다.

## 4-3. 반드시 먼저 정할 설계 결정 3가지

**① "그림 파일 0장 원칙"을 어디까지 깰 것인가**
`atlas.js` `icons.js` `trails.json` `world.json` 주석에 반복 등장하는 관통 원칙이다. AI활용 PDF 제출물에도 이 결정 근거를 써야 한다.
→ 권장: **절차 생성을 fallback으로 남기고 에셋을 위에 얹는 하이브리드.** 에셋 로드 실패해도 게임이 굴러간다.

**② 아바타 28,800 조합은 에셋으로 대체 불가**
레이어 + 팔레트 스왑 유지가 유일한 길. **인덱스 컬러 PNG 또는 마스크 채널**로 뽑아야 하는데, AI 툴은 기본적으로 RGB로 뱉는다 → **후처리 양자화 스크립트가 파이프라인의 필수 부품**이다.

**③ 최종 타일 배율**
`public/js/world.js`의 줌 배율 `tile` 값 확인 후 확정. 그 전에는 **32px/타일을 마스터**로 잡으면 안전(현재 16px의 2배 → 정수배 다운스케일 가능).
